# Контекст Figma Skills из прежних чатов

Снимок на 10 ноября 2026. Это путеводитель по найденной истории, а не замена исходных переписок. Перед работой сверяйте решения с актуальными файлами и Figma. Идентификаторы чатов пригодны для поиска на компьютере, где сохранена история; сами переписки с этим файлом не переносятся.

## Важное о версиях

Историческая рабочая папка: `/Users/r.bulatov/okko_agent_design`; другая локальная папка проекта — `/Users/r.bulatov/okko_claude_agent`. У них один Git remote. На момент подготовки контекста в первой папке версия и накопленные изменения были новее; вторая находилась на старой ветке. При работе с другого компьютера используйте актуальную ветку main и проверяйте состояние репозитория.

## Устойчивые ориентиры из истории

- В прежней рабочей папке правило AGENTS.md запрещает создавать новые дизайн-переменные и токены в проекте и связанных файлах Figma; используются существующие, при отсутствии нужного сообщить пользователю. Применимость этого правила к конкретной задаче уточнять по действующим инструкциям проекта.
- Репозиторий Token Studio — источник значений токенов; при работе с дизайн-библиотекой сверять актуальные данные и существующие привязки. В чате о синхронизации для этого сценария зафиксирован read-only доступ, без открытия плагина Token Studio.
- Документация компонентов разделяет Overview, гайд и паспорт. При обновлении гайда сверять старую и новую версии, чтобы сохранить ограничения, жесты, правила размещения и схемы. Черновые сведения не считать утверждённым поведением.
- Для hover контролов учитывать тип заливки и переопределения экземпляров в Overview и гайде. Специфические исключения конкретной задачи не превращать в общие правила.
- При актуализации Android-библиотеки в чате отмечены мастер-файл как источник и каталог Structure; проверять нынешнее состояние перед изменениями.
- Figma Specs для Select Web заполнен: https://www.figma.com/design/e72TWMOh7ibwauqgKwLnC9/Lib-Web?node-id=48511-3794 . Поведение реализации, доступность и значения токенов требуют проверки; идея общей синхронизации знаний со Specs ещё не утверждена.
- Rail card: исследование находится в `output/rail-card-kickoff/research-context.md`; работа с изображениями через плагин оставалась непроверенной.

В старой папке также есть более подробные материалы `figma-agent-skills/`, `design-system/`, `.agents/skills/` и отчёты `output/`. Их наличие в этой версии проекта или на другом компьютере нужно проверить отдельно.
