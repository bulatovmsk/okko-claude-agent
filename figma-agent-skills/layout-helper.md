# Skill: компоновка экранов из компонентов Okko

## Когда применять

Используй для структуры экрана, флоу и платформенной адаптации. Создавай или изменяй Figma-ноды только когда пользователь прямо попросил это сделать.

## Подготовка

1. Определи платформу, продуктовый контекст, главную задачу и состояния экрана.
2. Выбери lifecycle `ready` компоненты из `okko-ds-context.md` и проверь их в живой библиотеке.
3. Не подставляй воображаемый компонент. Недостающие части вынеси в список gaps.

## Проектирование

- Строй иерархию сверху вниз, называя реальные компоненты и properties.
- Используй существующие instances, variables, styles и auto layout.
- Покажи loading, empty, error, disabled и focus только когда они нужны сценарию.
- Для TV задай focus order, начальный фокус и возврат фокуса.
- Для mobile учитывай safe area, hit area, системную навигацию и жесты.
- Не переноси iOS-решение на Android, Web или TV как подтверждённое правило без источника.

## Запись в Figma

Не detach инстансы. Не изменяй исходные component sets. После создания проверь переполнение текста, bindings, auto layout, клиппинг, состояния и визуальную целостность.

## Результат

Верни цель и платформу, иерархию экрана, список компонентов и properties, ключевые токены, состояния и навигацию. Для созданного макета укажи frame/nodeId и пункты ручной проверки.
