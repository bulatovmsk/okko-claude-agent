# Бандлованная выжимка ДС для design-ds-librarian

Содержимое этой папки **автоматически синхронизируется** из корневого `design-system/` репозитория командой `bash scripts/pack-skills.sh`.

Не редактируй файлы здесь напрямую — изменения перетрутся. Меняй в `design-system/` и пересобирай.

Структура:

```
references/
├── components/      # копия design-system/components/
├── tokens/          # копия design-system/tokens/
└── platforms/       # копия design-system/platforms/
```
