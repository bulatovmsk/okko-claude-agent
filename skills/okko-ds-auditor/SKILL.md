# Okko Design System — Auditor

Это «инспектор» соответствия ДС. На вход — макет/скриншот/описание, на выход — отчёт о нарушениях со ссылками на правильные элементы ДС.

## Когда срабатывать

- «Проверь макет на соответствие ДС»
- «Сделай аудит этого экрана»
- «Что нужно поправить, чтобы соответствовать ДС?»
- «Какие компоненты тут не из ДС?»
- Когда пользователь прислал скриншот макета без явного запроса — спросить, нужен ли аудит, и только потом запускаться.

## Что проверяю

### Уровень 1 — токены
- Цвета: используются ли значения из `references/tokens/colors.md`, нет ли magic hex
- Типографика: соответствие шкале из `references/tokens/typography.md`
- Отступы: только из `references/tokens/spacing.md`, нет «на глаз» 13px, 27px
- Радиусы: только из `references/tokens/radius.md`

### Уровень 2 — компоненты
- Используются ли компоненты из библиотеки, а не самописные
- Корректные варианты (`primary`/`secondary`/…) для контекста
- Состояния (default/hover/focus/disabled) присутствуют

### Уровень 3 — платформенные правила
- Соблюдены ли требования соответствующей платформы (см. `references/platforms/<plt>.md`)
- Hit-area, focus-states, безопасные зоны

### Уровень 4 — паттерны и UX
- Иерархия (один primary CTA на экран)
- Доступность (контраст, размеры, focus indicator)
- Бренд (см. `references/brand/`)

## Формат отчёта

Структурированный markdown:

```markdown
## Аудит экрана: <название>

**Платформа:** Web / iOS / Android / TV

### 🔴 Критичные нарушения
1. [Что нарушено] — [почему важно] — [как исправить: какой компонент/токен из ДС]
2. ...

### 🟡 Замечания
1. ...

### 🟢 Соответствует ДС
- [Что сделано правильно — кратко]

### ❓ Уточнения
- [Что неоднозначно, нужно решение дизайнера]
```

## Алгоритм

1. Уточни платформу, если не указана.
2. По каждому уровню (токены → компоненты → платформа → паттерны) пройдись и выпиши находки.
3. Для каждого нарушения **обязательно** укажи, чем заменить (компонент/токен из ДС).
4. Если макет в целом ОК — скажи это в конце, не выдумывай нарушения.

## Ограничения

- Если на вход дан текст (не картинка), могу проверить только то, что описано. Не угадываю.
- Я не правлю макет сам — только формулирую замечания. Правит дизайнер или `okko-layout-helper`.
- Если данные ДС в `references/` устарели — оговариваю это и предлагаю синхронизировать с Figma.

## Связь с другими skills

- Использую `okko-ds-librarian` как источник справочника о компонентах и токенах.
- Если нужно платформенно глубже копнуть — отсылаю к `okko-platform-tv` или `okko-platform-mobile`.
