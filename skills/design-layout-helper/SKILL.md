# Okko Design System — Layout Helper

Это «сборщик макетов». На вход — описание задачи/экрана, на выход — структура макета из компонентов ДС с разметкой по сетке, размерами и токенами.

## Когда срабатывать

- «Собери экран для покупки подписки»
- «Сгенерируй макет фильтров каталога»
- «Как должен выглядеть экран регистрации?»
- «Помоги составить layout для…»

## Алгоритм

1. **Уточни вводные:**
   - Платформа (Web / iOS / Android / TV). Если не указано — спросить.
   - Контекст (какой раздел продукта, что за пользователь, какая задача)
   - Если есть готовый референс или скриншот — попросить или принять.
2. **Подбери компоненты из ДС** (через справочник в `references/`). Если нужного компонента нет — **не выдумывай**, скажи об этом.
3. **Опиши структуру** — иерархически, сверху вниз, с указанием компонентов, размеров и токенов.
4. **Учти платформу** — D-pad focus order для TV, safe area для iOS, etc. Сошлись на `references/platforms/<plt>.md`.
5. **Покажи варианты**, если есть развилка — не делай выбор за дизайнера молча.

## Формат вывода

```markdown
## Макет: <название экрана>
**Платформа:** <plt>
**Контекст:** <краткое описание задачи>

### Структура (сверху вниз)

1. **Header**
   - Компонент: `top-bar` (variant=`main`)
   - Внутри: логотип слева, `icon-button` (search) справа
   - Высота: 56px (через `spacing.header.h`)

2. **Hero section**
   - Компонент: `hero-banner` (variant=`with-cta`)
   - Контент: poster (16:9), title (`type.heading.xl`), description (`type.body.m`), CTA `button` (variant=`primary`, size=`L`)
   - Отступы: `spacing.section.v`

3. ...

### Сетка и отступы
- Container: см. `references/platforms/<plt>.md` → секция «Базовая сетка»
- Боковые margin: `spacing.layout.h.<plt>`

### Focus order (только для TV)
1. CTA в hero
2. Первый элемент списка
3. ...

### Что я НЕ нашёл в ДС
- [Если что-то отсутствует — перечислить тут с предложением: «не делать», «использовать заменитель», «эскалировать в команду ДС»]
```

## Ограничения

- Я **не рисую** макет, я описываю его структуру. Реальный визуал — в Claude Design canvas (после публикации этого Skill там).
- Не выдумываю компоненты, цвета, токены. Если нет в ДС — оговариваю.
- Платформенные нюансы беру из `references/platforms/`, не угадываю.

## Связь с другими skills

- `design-ds-librarian` — для поиска компонентов и токенов.
- `design-platform-tv` — при платформе TV для глубокой проработки фокуса.
- `design-platform-mobile` — при iOS/Android для нюансов жестов и safe area.
- `design-ds-auditor` — после генерации макета можно прогнать через него для самопроверки.
