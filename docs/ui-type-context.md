# Контекст UI Type Rail

Состояние на 16 ноября 2026. Точка продолжения на рабочем MacBook.

## Цель и инструменты

По концепту дизайнера любой детализации собирать полноценную компонентную основу Rail для iOS, Android и Web; дизайнер затем донастраивает результат.

- Codex: $build-ui-type — все платформы или выбранный поднабор; $rail-layout-guides — сетки. Отдельный iOS-скилл удалён.
- Figma Agent: /okko-build-ui-type. Шесть Guidelines и файл команды находятся в figma-guidelines/; инструкция загрузки — в README этой папки.
- Подробные правила и карта мастеров уже сохранены в .agents/skills/build-ui-type/references/. Перечитывать старую переписку для новой сборки не требуется.

Основная библиотека: https://www.figma.com/design/TGfdPRzrhCA6CbiHsRjBSD

## Ключевые решения

Карточки и общий Heading берутся из UI Type, базовые компоненты — из платформенных библиотек. Совместимые запчасти переиспользуются. Мастера iOS → Android → Web стоят в ряд без секций-обёрток.

Отклонение пропорции до 15% включительно — ближайшая подходящая фиксированная пропорция; больше — Custom. Радиус выбирается по минимальной стороне через существующий токен Rail Card; шкала рекомендательная. Явные настройки дизайнера сохраняются. iOS использует утверждённые фиксированные размеры, Android — сетку, Web — свою формулу. Новые переменные и токены создавать запрещено.

## Последний тест

Figma Agent собрал Rail Media: https://www.figma.com/design/JaOP0vDUAU2uYmJ1vR8u2v?node-id=2013-6329

Это отдельный тестовый файл, не основная библиотека. Наборы: iOS 2013:9888, Android 2013:14134, Web 2013:17990.

- Время 13:34, стоимость 578 из 3500 месячных кредитов (16,5%).
- Аудит Codex подтвердил 14 вариантов (5/3/6), 112 связанных карточек, настоящие слоты, переменные gap/radius и корректную геометрию. Видимые тексты 48 Web-карточек совпали с концептом; максимум четыре строки сохранён.
- На Web 320 переход 272×373 → Vertical 272×408 соответствует правилу 15%, это не ошибка.
- Ещё не исправлены: дублирующие Overlay Web Tablet 2013:6405 / Desktop M 2013:6420; отсутствие Show heading у Android. Замена Sorem на Suisse Int’l на Native требует решения дизайнера.
- Переключение тем и прототипные переходы отдельно не проверены. Стоимость точечных исправлений пока неизвестна.

## Продолжение

На Mac открой актуальную main этого репозитория и попроси Codex прочитать этот файл. Для новой сборки вызови $build-ui-type с концептом. Для продолжения теста сначала выбери нужное замечание и сверь живую Figma; исправления по итогам аудита ещё не выполнялись.

Открыты вопросы внутренних Rail Card Padding Gap, хранения Web R/N в Technical и поведения между Web-брейкпойнтами. Публикация основной библиотеки не подтверждена. Первоначальная причина неполучения Guidelines агентом по скриншоту не установлена; skill уже ищет локальные мастера в текущем Figma-файле/ветке и содержит резервные правила.
