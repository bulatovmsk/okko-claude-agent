# Контекст проекта Figma Skills

Обновлено: 11 ноября 2026. Это рабочая точка входа; перед изменениями сверяйте сведения с текущими файлами репозитория и Figma.

## Назначение

Репозиторий содержит навыки и знания для работы с дизайн-системой и библиотеками Figma. Навыки находятся в `.agents/skills/`, сведения о дизайн-системе — в `design-system/`, инструменты — в `scripts/`. Подробнее: [README](../README.md).

## Правила и источники

- Прочитайте [AGENTS.md](../AGENTS.md) и применимые инструкции перед работой. В проекте действует запрет на создание новых Figma-переменных и токенов; используются существующие привязки. При нехватке переменной сообщите об этом.
- Репозиторий Token Studio используется как источник значений токенов при чтении; перед выводами проверяйте актуальную версию. Состояние библиотек и привязок проверяется в Figma.
- Сведения, извлечённые из истории, и указатель обсуждений находятся в [CONTEXT_FROM_CHATS.md](../CONTEXT_FROM_CHATS.md). Это исторический снимок, не подтверждение текущего статуса задач.

## Работа с двух компьютеров

Перед началом проверьте рабочее дерево, ветку и обновите её из GitHub, не перезаписывая незакоммиченные изменения. После значимых решений обновляйте этот файл и [указатель](chat-index.md), проверяйте diff и публикуйте изменения. Не храните здесь историю другого проекта.

Оба репозитория публичны. Не добавляйте секреты, личные данные или внутренние материалы без проверки допустимости публикации. Экспорт чатов не создаёт чаты в интерфейсе ChatGPT.
