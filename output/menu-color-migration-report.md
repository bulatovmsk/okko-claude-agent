# Menu — миграция цветов

Проверка завершена 20.10.2026. Работа начата 19.10.2026.

[Страница Menu](https://www.figma.com/design/sb7SelAF2PBcYZsOxL092c/?node-id=503-0), fileKey sb7SelAF2PBcYZsOxL092c, page 503:0.

Выполнена однозначная часть. Страница целиком не очищена от старых цветов: в ней остаются исключённые области и спорные соответствия.

## Что изменено

- В разрешённой области страницы напрямую обновлены цвета у **917 уникальных слоёв**. Это 954 фактических изменения привязок с учётом повторного перевода части уже мигрированного текста в static.
- 868 замен выполнено по согласованной таблице Deprecated → color.
- Ещё 16 прямых замен выбраны по подтверждённой роли: 7 основных фонов старых хедеров/футеров → background/solid/primary, 2 собственных разделителя футера → border/glassy, 5 полосок активного пункта → border/decorative/active-horizontal, 2 включённых переключателя → fill/solid/accent. Связанные разделители в экземплярах обновились автоматически.
- Live: один слой исходного небольшого мастера 28:22 на странице «Элементы» получил fill/solid/live; ещё 12 оставшихся переопределений изменены непосредственно в Menu. Все 132 старых красных применения Live в разрешённой области обновились непосредственно либо по наследованию.
- Static: 58 прямых замен плюс 52 изменения по наследованию перевели 110 белых текстовых/иконочных заливок на цветных фонах на static/solid/white. С учётом ранее корректных — 133 static-заливки. Повторная проверка: подходящих белых/чёрных тематических привязок на проверенных цветных фонах не осталось.
- Прямые записи выполнялись в мастерах и разрешённых цветовых переопределениях внутри мастеров. Общего reset overrides, detach или swap не было. Фоны/варианты Light и Kids напрямую не мигрировались, кроме ранее утверждённых конкретных исключений on Light → inverse.
- Сырые цвета без токена/стиля не менялись. В проверке static отдельно оставлены 26 сырых заливок и 12 серых подписей без однозначного static-эквивалента.
- Новые переменные, токены, aliases, коллекции и стили не создавались.

Для static сохранена итоговая прозрачность: при переходе к opaque static/solid/white прежняя alpha перенесена из paint в opacity самого текста/иконки. Цвет и произведение paintOpacity × nodeOpacity проверены после записи. Слои с конфликтующими эффектами, маской, обводками или opacity-binding не включались в такую замену.

## Полная проверка и остатки

Полностью обойдены **41 761 узел и 49 корней**, включая скрытые слои, старые блоки, вложенные инстансы, оформленные текстовые диапазоны, градиентные stops, fills, strokes, effects и отдельные области векторов. Ошибок чтения нет; непрочитанных mixed-полей нет.

Повторный аудит источников paint styles обнаружил **9 571 старое применение**, с непересекающимися причинами:

| Причина | Применений |
|---|---:|
| Вне мастеров: продуктовые примеры, гайды, оформление и их инстансы | 8 505 |
| Light, исключая Kids | 804 |
| Kids | 88 |
| Спорные применения в разрешённых мастерах | 174 |

В разрешённой области не осталось неприменённых однозначных соответствий из согласованной таблицы Deprecated. Все 174 спорных применения относятся к 15 старым источникам Primitives/Clickable/AccentB/Elevation и перечислены далее.

Дополнительно найдены 3 привязки color/text-icon/secondary к старой коллекции Theme. Все три — вне мастеров, в примерах [WEB] Имя профиля; прямых записей там не было. Эти variable-привязки приведены отдельно от счётчика старых paint styles.

Найдено также 42 применения старого Color/fill/solid/hover-focus/Third, key 7190d7e2c06681786a2e62457fbad4e50931c325. Все — в примерах вне мастеров, внутри Betting-логотипа; уже включены в 8 505. Префикс Color не делает эту версию актуальной: её ключ отличается от опубликованного актуального стиля.

Старые Blur/Тень effect styles не учитывались как Deprecated paint styles: определения эффектов не заменялись по таблице цветов. Их цветовые variable-bindings были прочитаны в полном аудите.

Selection colors в UI не открывалась. Проверка программная, по источникам каждого поля. Визуально проверены актуальный Mobile Menu и активный пункт.

## Данные и границы журнала

menu-color-migration-audit.json содержит полные ID всех 174 спорных применений в мастерах, ID изменённых слоёв, результаты записи и агрегированный полный аудит всей страницы с примерами по каждому источнику. Формат строки eligible.rows: [nodeId, field, sourceKeyIndex, masterId, nodeName]. Полный перечень ID 8 505 внешних применений в локальный JSON не экспортирован; их источники и количества получены полным обходом. REST-экспорт недоступен, поскольку в проекте не настроен .env; это не ограничило Figma-аудит или запись через подключённый инструмент.

Два первоначальных read-only ответа пришлось сократить из-за лимита вывода инструмента. Финальные данные получены без усечения. При проверке новых static-привязок автоматическое наследование учитывалось отдельно: уже обновившиеся экземпляры не прибавлены к прямым заменам.
