# Концепт rail card: контекст исследования

Снимок решений из чата «Подготовить концепт карточки рейла» на 6 ноября 2026. Это рабочий концепт, не утверждённая спецификация дизайн-системы; перед продолжением проверь [живой файл](https://www.figma.com/design/bDs5VQELpsfm4ynrz1d02H/). UI type — готовый шаблон из карточек и заголовка; rail card — сама настраиваемая карточка. Цель — ускорить работу дизайнеров, уменьшить вложенность и сложность свойств; возможности Figma могут отличаться от будущего конструктора в коде.

- Сравнивались три подхода к настройке, в том числе слоты, swap и Boolean. Исследования дизайнеров показали ценность кастомизируемых слотов после освоения; одновременно названия слотов и длинные списки Boolean затрудняли понимание. Это ранние наблюдения, не итоговый выбор решения.
- Существующие UI type должны оставаться удобной отправной точкой для продуктовых команд: добавить элементы, подписи и изменить размер. Лейблы, включая Rich Label, предусмотрены внутри карточки, а не только через слот.
- В концепте во все 24 варианта карточек 01, 02 и 03 для Phone и Tablet добавлен технический прямоугольник `Cover` по [образцу](https://www.figma.com/design/bDs5VQELpsfm4ynrz1d02H?node-id=45962-58538), под содержимым обложки, с растяжением. Он нужен плагину для подстановки изображений из продовых коллекций. Наличие и растяжение проверены на экземплярах; **подстановка самим плагином ещё не проверена**.
- При последующих изменениях проверяй все три подхода, формы и устройства, сохранение лейблов, поведения слотов и технического слоя. Не распространяй этот контракт на другие семейства карточек без подтверждения.
