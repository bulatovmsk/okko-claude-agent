# Rail: замена цветов

Дата: 20 октября 2026. [Страница UI Type → Rail](https://www.figma.com/design/sb7SelAF2PBcYZsOxL092c/?node-id=16685-178431).

Изменены **1 498 уникальных слоёв**. Проверены 579 мастер-компонентов, включая вложенные инстансы: **94 063 слоя**. В подсчёте изменений каждый слой учитывается один раз, даже если исправлены несколько свойств.

Обновлены однозначные соответствия старых стилей существующим color-токенам. Исправлены фокусные обводки, включая два градиентных stroke на одном векторе, старые варианты Secondary у иконки «Больше», заливка Continuum. На 16 слоях текст/иконки на цветном фоне получили существующие static white/black с сохранением видимой прозрачности.

Проверка выполнена программно по fills, strokes, регионам векторов, привязкам градиентных остановок, текстовым диапазонам и эффектам. Ошибок финальной проверки и неразрешённых ссылок на стили нет. В собственных слоях мастеров доступных тем старых paint-стилей не осталось; перечисленные ниже остатки находятся во вложенных инстансах.

## Исключённые темы

- Light: **1135** применений старых paint-стилей.
- Kids: **96** применений старых paint-стилей.

Это количество ссылок на старые paint-стили, а не число уникальных цветов или слоёв. Дополнительные привязки переменных сохранены в JSON отдельно и не прибавлены к этим числам.

Light/Kids исключены из адресных изменений. Сырые цвета без токенов оставлены. Новые переменные, aliases, коллекции и стили не создавались. Импортировались только существующие библиотечные ресурсы.

Вложенные цвета исправлялись адресными переопределениями в обработанных мастерах, когда источник недоступен или изменение общего источника не подходит всем контекстам. Геометрия, тексты, свойства вариантов и прочие переопределения не менялись. Фокусный градиент заменён на solid по ранее согласованному правилу.

## Границы проверки

Проверены все 579 мастер-компонентов страницы с их деревьями, включая скрытые слои и вложенные инстансы. Иллюстрации, примеры и оформление за пределами мастеров полностью не сканировались и не редактировались. Попытка полного обхода страницы упёрлась в время ответа Figma; аудит выполнен по исчерпывающему списку реальных мастеров в девяти группах. Проверка панели Selection colors вручную не выполнялась.

Поэтому Selection colors при выборе всей страницы ещё может показывать старые цвета из исключённых тем, перечисленных 282 применений и внешних примеров.
