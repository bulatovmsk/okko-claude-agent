## 1. Шапка ✅

**Select · Web**

Компактный контрол-фильтр: показывает уже применённый выбор и открывает список опций.
В отличие от Chips, прячет варианты за одним контролом — для длинных списков.

- Размеры: `Small` и `Default`, три брейкпоинта — `320+`, `600+`, `1720+`
- Состояния: Desktop и Tablet — Rest / Hover / Focus / Pressed / Disabled; Mobile — без Focus
- Устойчивый выбор `Selected` — отдельная ось, не то же самое, что `Pressed`
- Счётчик выбранного через `Show Counter` + `Count`
- Работает в общей группе с Chips — см. [Раздел 15](#15-схема-каталога-chips--select-)

Якоря-чипы: `[Назначение]` `[Когда использовать]` `[Анатомия]` `[Настройки]` `[Размеры]` `[Состояния]`
`[Selected]` `[Зоны нажатия]` `[Do/Don't]` `[Каталог]` `[Ссылка на паспорт]`

> ❓ Иллюстрации в контексте для шапки не подобраны: production-скриншотов с Select Web нет.

## 2. Когда использовать ✅

- Длинный список опций, который не помещается на экран россыпью тегов
- Множественный выбор с подсчётом: «Жанры · 3», «Страны · 5»
- Единичный выбор из списка
- Экономия места: один контрол вместо набора Chips

Поведение ✅: `Selected=False` — вся площадь открывает список.
`Selected=True` — основная часть открывает список, правая зона сбрасывает выбор.

> ❓ Иллюстрации в контексте: нужны реальные экраны Окко с Select. Не подбирать синтетические
> без пометки «схема».

## 3. Когда НЕ использовать ✅

| Сценарий | Вместо |
|---|---|
| Короткий список, все варианты помещаются в строку | **Chips** — раскрывают короткие варианты прямо в строке |
| Десктопный список, раскрывающийся без шторки | **Dropdown** — связанный компонент, не вложенная часть Select |

⚠️ Выбор между Select и Dropdown требует решения: у Dropdown брейкпоинты `1720`/`1320`,
у Select — `1720+`/`600+`/`320+`. Формального соответствия нет.

## 4. Анатомия компонента ✅ ⚠️

Публично управляемые части:

1. **Корень (контейнер)** — auto layout, несёт высоту, радиус и левый отступ по осям `Size` и `Breakpoint`
2. **Лейбл** — свойство `Text`, стиль `Button Small` или `Button Default` по размеру
3. **Ведущая иконка** — по `Show Icon` (Boolean) и `Icon` (instance swap); только вместе с текстом
4. **Счётчик** — `Count` (TEXT), виден при `Selected=True` и `Show Counter=true`
5. **Трейлинг-зона** — `Selected=False`: стрелка вниз; `Selected=True`: `Actions / Cross_Small_Bold`
6. **Слой рамки фокуса** — `_Select - Border`, отдельная белая обводка 1 px, opacity 56%, отступ 2 px, радиус корня + 2

Легенда выносок (фиолетовые номера, конец выноски точно на часть):

- ↗ Корень — `control/{small|default}/height/{phone|tablet|desktop}`, `.../radius/...`
- → Лейбл — стиль `Button Small` / `Button Default`
- ↘ Ведущая иконка — `Show Icon` + `Icon`
- ↙ Счётчик — `Show Counter` + `Count`
- ← Трейлинг — стрелка / `Actions / Cross_Small_Bold`
- ↖ Focus-рамка — `_Select - Border`, только Desktop и Tablet

> ⚠️ Выносок должно быть по числу значимых частей, а не «сколько влезло». Для иллюстрации
> брать связанный инстанс, на котором видны и счётчик, и крестик (`Selected=True`,
> `Show Counter=true`).

## 9. Состояние выбора (Selected) ✅ ⚠️

`Selected` — устойчивый выбор, отдельная ось от `Pressed`. Не смешивать «список открыт», `Selected` и `Pressed`.

- `Selected=True` использует `color/fill/solid/inverse`
- Опционально показывается счётчик: `Show Counter=true` + `Count`
- Трейлинг-иконка меняется на `Actions / Cross_Small_Bold` — правая зона сбрасывает выбор

> ⚠️ Отдельного hover-токена для `inverse` при проверке не найдено — **не выдумывать** его.
> ❓ Утверждение «Selected переключается только при открытии» требует подтверждённого источника:
> в iOS-гайде формулировка противоречива, а прототипные события и API кода не проверены.

## 10. Иконки ✅ ⚠️

- Ведущая иконка управляется `Show Icon` (boolean) и `Icon` (instance swap)
- Трейлинг при `Selected=True` — `Actions / Cross_Small_Bold`
- Правая иконка лежит в `Trailing Icon`: горизонтальный auto layout, Hug по ширине, Fill по высоте,
  центрирование по вертикали. Правый padding корня — **0**, правый padding контейнера привязан к
  `control/small/filter-icon/padding-horizontal/{device}` для обоих размеров
- Слева по решению пользователя: фиксированные 14 px Mobile / 18 px Tablet; справа 18 / 22 px,
  **без привязки ширины и высоты к компонентным токенам** — это осознанное решение, не ошибка

> ⚠️ **Desktop не нормализовать молча.** Последний снимок: слева 20 px, справа обычно 24 px,
> в отдельных вариантах иные размеры и привязка `control/default/text-icon/icon-size/desktop`.
> Текущую неоднородность нельзя выдавать за согласованное правило — нужно решение команды.

## 14. Как использовать (Do / Don't) ✅ ❓

Черновик на подтверждённых сценариях — формулировки требуют ревью дизайнера.

**Пара 1 — выбор компонента**
- ✅ Do: длинный список жанров — `Select` со счётчиком «Жанры · 3».
- ❌ Don't: три жанра, помещающиеся в строку — `Select` вместо Chips. Лишний тап и скрытое состояние.

**Пара 2 — различение выбора и нажатия**
- ✅ Do: `Selected=True` показывает применённый фильтр и остаётся после закрытия списка.
- ❌ Don't: считать `Pressed` подтверждённым выбором. Момент нажатия ≠ применённый фильтр.

**Пара 3 — сброс**
- ✅ Do: при `Selected=True` сброс — правой зоной с `Cross_Small_Bold`.
- ❌ Don't: оставлять весь контрол одной зоной открытия, когда выбор уже применён: пользователь
  не сможет сбросить фильтр одним действием.

**Пара 4 — группа с Chips**
- ✅ Do: `Chips` и `Select` стоят вместе над выдачей — короткие варианты раскрыты, длинные спрятаны.
- ❌ Don't: разносить их по разным местам экрана: пользователь не понимает, что это одна группа фильтров.

> ❓ Не выдумывать антипаттерны, которых в продукте Окко не бывает. Пары 3 и 4 требуют
> подтверждения у дизайнера.

## 15. Схема каталога Chips + Select ✅

Подтверждено пользователем: **Select используется в каталоге в общей группе с Chips**, гайд должен
показывать их вместе над выдачей.

- `Chips` раскрывают короткие и быстрые варианты прямо в строке
- `Select` открывает список
- За компоновку группы и выдачу отвечает **Filters Catalog** (`27582:114073`), а не сам Select

> ⚠️ Схема каталога — **не** production-скриншот. Подписать это явно в гайде.

## 16. Связь с Dropdown ✅ ❓

**Dropdown** (`22080:330029`) — связанный десктопный список, а **не** вложенная часть Select.

> ❓ У Dropdown значения брейкпоинтов `1720`/`1320`, у Select — `1720+`/`600+`/`320+`.
> Соответствие и мобильный способ раскрытия требуют решения. Не описывать Dropdown как
> «шторку Select».
