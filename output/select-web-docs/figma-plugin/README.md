# Okko Doc Builder · Select Web

Плагин переносит черновики документации Select · Web в Figma — в существующие фреймы
`Guide · Select · Web` и `Passport · Select · Web` файла **Lib-Web** `e72TWMOh7ibwauqgKwLnC9`.

## Почему плагин, а не прямая запись

Инструмента записи у агента нет: коннектор `mcp.figma.com` отвечает 401, `use_figma` в сессии
недоступен. Плагин — тот же путь, что и со smoke-тестом: запись выполняет Figma по вашему запуску,
агент отвечает за контент и проверку.

## Что плагин делает

- Дополняет **только выбранный фрейм** и только если в его имени есть `Guide` или `Passport`.
  Не угадывает цель и не пишет наугад.
- Создаёт секции черновика: заголовок, абзацы, буллиты, заметки, таблицы, блок кода.
- **Оформление снимает с живого файла**: шрифты, кегли и цвета берёт из существующих текстов
  выбранного фрейма, ширину контентной колонки — из его детей. Если снять не удалось, применяет
  токены ДС и сообщает об этом.
- **Идемпотентен**: секция с таким именем уже есть — пропускается. Повторный запуск не плодит копии.
- Существующие ноды не изменяет, инстансы не отсоединяет, исходный компонент Select не трогает.

## Чего плагин НЕ делает

- **Не рисует визуальные секции.** Анатомия с фиолетовыми выносками, иллюстрации, Do/Don't
  в зелёной и красной рамках, применение в полном экране — это отдельная работа с инстансами
  и Pointer-шаблонами библиотеки. Плагин переносит **содержание**, а не графику.
- Не создаёт и не изменяет компоненты, варианты и переменные.
- Не подбирает ссылки между гайдом и паспортом — их нужно назначить вручную.

## Запуск

1. Откройте **Lib-Web** (`e72TWMOh7ibwauqgKwLnC9`) в Figma Desktop.
2. `Plugins → Development → Import plugin from manifest…` → выберите `manifest.json` из этой папки.
3. Выделите фрейм **`Guide · Select · Web`** (`46763:2394`).
4. Запустите **Okko Doc Builder · Select Web** — в конец гайда добавятся 17 секций.
5. Выделите фрейм **`Passport · Select · Web`** (`46763:2575`) и запустите плагин снова — добавятся 10 секций.

Нотификация покажет, сколько секций создано, сколько пропущено и сколько нод добавлено.
Отменить результат целиком можно через `Cmd+Z`.

## Пересборка после правки черновиков

Контент встроен в `code.js` из черновиков. Правите `.md` — пересобираете:

```bash
cd output/select-web-docs/figma-plugin
python3 build-plugin.py
node --check code.js
```

| Файл | Роль |
|---|---|
| `plugin-template.js` | движок: снятие оформления, рендер блоков, идемпотентность |
| `build-plugin.py` | парсер черновиков Markdown → встроенный JSON |
| `code.js` | **собранный плагин**, его и запускает Figma. Не править вручную |
| `manifest.json` | манифест для импорта |

## Ограничения текущей версии

- Тексты переносятся как есть, включая пометки ✅ ⚠️ ❓ — по ним дизайнер видит, что проверено,
  а что нет. Хвостовые маркеры из имён фреймов убраны.
- Таблицы рендерятся ячейками текста без сортировки и без объединения столбцов.
- Кегль заголовков секций ограничен диапазоном 18–32, кегль текста — 11–18, чтобы крупный
  декоративный текст из библиотеки не превратился в заголовок раздела.
- Ссылки из Markdown переносятся как текст, гиперссылки не назначаются.
