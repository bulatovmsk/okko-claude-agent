## Порядок сборки, когда появится запись

1. Открыть Lib-Web, прочитать живые `21983:326646`, `46763:2394`, `46763:2575`, `46767:1861`, `46767:2468`.
2. Сверить черновики с фактическими слоями и привязками (список ниже), снять расхождения.
3. Дополнить существующие фреймы секциями из черновиков, переиспользуя шаблонные секции и инстансы страницы Filters.
4. Переиспользовать общую `SECTION` без имени; компонент слева, гайд по центру, паспорт справа.
5. Проверить: отсутствие обрезки и пересечений, читаемость таблиц, назначенные ссылки, связи инстансов, номера выносок против легенды.

## Чек-лист ручной проверки

Всё ниже помечено в черновиках как ⚠️ или ❓ — эти места нельзя публиковать без проверки.

- [ ] **Иконки Desktop.** Последний снимок: слева 20 px, справа обычно 24 px, в части вариантов иные размеры и привязка `control/default/text-icon/icon-size/desktop`. Не нормализовать молча и не выдавать текущую неоднородность за правило.
- [ ] **Ширина Select.** В таблице геометрии ширина отсутствует: считать ли её «по содержимому» — не подтверждено.
- [ ] **Прототип и переключение Selected.** Утверждение «Selected переключается только при открытии» нужен подтверждённый источник: в iOS-гайде формулировка противоречива, а события и API кода не проверены.
- [ ] **Маппинг Dropdown.** У Dropdown брейкпоинты 1720/1320, у Select — 1720+/600+/320+. Соответствие и мобильный способ раскрытия — решение команды.
- [ ] **Клавиатура.** Enter/Space, Tab и доступная семантика **не проверены** — в черновике это предлагаемый контракт, а не реализация.
- [ ] **Лимит подписи и обрезка.** Не подтверждены; поведение при переполнении неизвестно.
- [ ] **Множественный выбор.** Применение множественного выбора и интеграция в коде не проверены. Не присваивать Ready.
- [ ] **Правый padding.** Привязан к `control/small/filter-icon/padding-horizontal/{device}` для обоих размеров; Desktop-значение пользователь менял — сверить живую привязку.
- [ ] **Focus-рамка.** Слой `_Select - Border` — не инстанс `_Button - Border`. Проверить растяжение при смене текста и видимости счётчика.
- [ ] **Do/Don't.** Пары построены на подтверждённых сценариях, но формулировки требует дизайнер.
- [ ] **Иллюстрации в контексте.** В черновике их нет: нет production-скриншотов.
- [ ] **Схема каталога и таблица настроек.** Подписать как схемы: это не production-экран и не снимок панели Figma.

## Чего не хватает

- Production-скриншотов с Select в реальном экране — секция «Применение в полном экране» не собрана.
- Решения по Desktop-иконкам и по ширине компонента.
- Подтверждённого контракта клавиатуры и поведения при переполнении подписи.
- Решения по мобильному раскрытию списка и соответствию Dropdown.
