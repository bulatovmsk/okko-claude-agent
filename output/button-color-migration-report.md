- Selection colors в интерфейсе не открывалась: выполнен программный аудит источников, включая региональные стили. Смешанные заливки 12 векторов полностью разобраны по областям.

## Исходный Bet Logo

Найден по совпадающему component key 6785229d12d18ed872819dd28997f34372cacf43.

[Исходный мастер](https://www.figma.com/design/HYB1u9ysALVWtVWKoagiDH/?node-id=24376-3484), page 1878:0, Vector 24376:3562. Две области получили существующую переменную color/fill/solid/inverse. Сырые заливки соседнего Vector не изменялись. Источник не публиковался.

Проверка контуров: топология совпадает; максимальное отличие координат от нормализованной исходной геометрии — 0.000001053 px в масштабе мастера (округление API). Контуры сохранены с допуском 0.000002 px. Буквальное JSON-сравнение до/после возвращало false из-за округления.

На рабочей странице 12 экземпляров сохранили прежнюю региональную inverse-привязку. Следующий шаг для них: проверить получение библиотечного обновления и отдельно оставшееся переопределение через UI/исходный мастер. Не считать одно обновление мастера доказательством очистки этих экземпляров.

## Журнал

Первый пакет 200 записей завершился тайм-аутом ответа инструмента. Следующее полное чтение подтвердило сохранение всех 200 замен: 88 primary text, 53 secondary text, 40 glassy third и 19 hover-focus third. Все последующие 2 375 локальных записей вернули ID и прошли проверку новых target bindings.

Полные ID оставшихся применений и журнал остальных изменённых узлов сохранены в button-color-migration-audit.json. Формат строки остатка: [nodeId, field, masterId, instanceAncestorId].
