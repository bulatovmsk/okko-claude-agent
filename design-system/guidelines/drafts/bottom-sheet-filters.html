BottomSheetFilters

Шаблон шторки выбора (Шаблоны шторки / Фильтры) с поиском, списком опций и кнопками внизу. Появляется при тапе на Select — раскрывает список значений фильтра. Построен на Sheet Native.

Источник: Lib-iOS (rMcDm5qGp4CXkXXddEbcMh) · COMPONENT_SET 37390:49620 · база — 🟢Sheet Native (37371:7396). Тема — Dark.

  • Header (заголовок фильтра + ×), Search Input, прокручиваемый список опций, две кнопки внизу: Сбросить и Применить
  • 4 заложенных варианта логики выбора — сингл с дефолтом / мульти без / сингл без / выбор города
  • Адаптируется под iPhone (прижат к низу) и iPad (плавающий по центру)

Когда использовать

  • Раскрытие списка опций по тапу на Select
  • Выбор значений фильтра с поиском и подтверждением (Применить / Сбросить)
  • Длинный/прокручиваемый список опций, который не помещается в Chips

Анатомия

Инстанс 🟢Sheet Native (Scrim + Sheet + Header), у которого Slot Box заполнен содержимым фильтра:

  1. Header (48pt) — заголовок фильтра + кнопка закрытия (×)
  2. Search Input (54pt, Searchbar) — поиск по списку опций
  3. List — прокручиваемый список строк List Item V2 (52pt каждая)
  4. Button Box (футер) — две кнопки Button 190×48: Сбросить и Применить

Наследует от Sheet Native: scrim (чёрный 56%), радиус листа 16 (iPhone — только верхние углы, iPad — все углы).

Варианты фильтра

В шаблоне заложены 4 варианта логики. Отличаются изначальным состоянием, типом выбора и поведением кнопок.

ВариантСтартТип выбора «Сбросить»Что показывает Select× на Select
1. Сингл с дефолтом дефолтное значение выбрано (✓)одиночный есть; disabled пока стоит дефолт имя выбранного значения сброс до дефолта
2. Мульти без дефолта всегда пустомножественный (по «ИЛИ») есть; disabled пока пусто counter (число выбранных) очистка до пуста
3. Сингл без дефолта пустоодиночный есть; disabled пока пусто имя значения + × очистка до пуста
4. Выбор города город всегда выбранодиночный, обязательный, с поиском нет — значение обязательно имя города — нельзя очистить

Множественный выбор всегда работает по принципу «ИЛИ». Единичный — при смене значения предыдущее сбрасывается.

Кнопки: Применить / Сбросить

Применить

  • Присутствует всегда. Применяет выбор и закрывает шторку
  • Выбор применяется только по этой кнопке
  • В выборе города — на всю ширину (т.к. «Сбросить» нет)

Сбросить

  • Disabled, пока выбор не менялся (дефолт для №1, пусто для №2–3)
  • Активируется, как только выбор изменён
  • Возвращает к изначальному состоянию (дефолт / пусто)
  • В выборе города кнопки нет

Закрытие шторки без «Применить» (×, свайп вниз, тап по затемнению) — выбор не применяется: фильтр остаётся как был.

Поиск внутри шторки

Показ поля поиска зависит от числа вариантов в списке.

Поведение списка

  • Первое посещение — список в обычном порядке
  • Повторное посещение — ранее выбранные пункты поднимаются наверх списка
  • Снятие выбора при повторном входе — снятые айтемы остаются на своих местах

Применение в продукте

Шторка вызывается тапом на Select в строке фильтров каталога / категории / Афиши.

Реальные экраны

Сценарий — мультивыбор «Жанр»

  1. Тап по Select «Жанр» → шторка «Жанры» (пусто, «Сбросить» disabled; поиск если жанров >20).
  2. Отмечаем Ужасы / Приключения / Комедии → «Сбросить» активна.
  3. «Применить» → шторка закрывается, Select показывает counter «Жанры · 3» и уезжает в начало строки (анимация 300 ms).
  4. Повторное открытие — выбранные жанры показаны наверху списка.

Сценарий — сортировка (сингл с дефолтом)

  1. Тап по «Сортировка» → шторка с выбранным по умолчанию «Рекомендуемые ✓», «Сбросить» disabled.
  2. Выбираем «А-Я» → предыдущее значение сбрасывается, «Сбросить» активна.
  3. «Применить» → чип показывает имя «А-Я».

Уникальный кейс — выбор города

  • Город обязателен и всегда имеет значение → «Сбросить» отсутствует, только «Применить» на всю ширину.
  • Есть поиск «Найти город» (всегда).
  • Выбранный город закреплён вверху списка, остальные — по алфавиту.
  • Полноэкранная подача (поверх главного экрана), не компактная шторка.

Тех-долг

⚠️ Строки списка собраны на 🟡 List Item V2 — статус «в работе», не финальный.

⚠️ Унаследовано от Sheet Native: кнопка закрытия в хедере — 🔴 [Deprecated] mini Button. Заменить при стабилизации.

⚠️ Расхождение паттерна: в шторке Афиши «Сбросить» — внутри шторки; в sort-шторке каталога «Применить» на всю ширину, а сброс вынесен на страницу. Требует унификации.

Связанные компоненты

  • Select — вызывает эту шторку при раскрытии
  • Sheet Native — база, на которой собран шаблон (scrim, Sheet, Header)
  • BottomSheet (кастомный) — для произвольного контента шторки, когда нужен контроль detent/высоты/жестов
  • Chips — альтернатива, когда варианты помещаются на экран без шторки
  • List Item V2 — строка опции в списке
  • Search Input — поиск по списку
  • Button — кнопки футера
