Фильтры

Группа компонентов фильтрации Окко: Chips, Select и шторка выбора BottomSheetFilters. Документ описывает, какой компонент выбрать, как ведут себя кнопки и какие бывают типы фильтров и краевые случаи.

Три компонента группы

Chips

Компактный выбор, когда варианты помещаются на экран. Живут строкой, поддерживают «выбран».

iPhone 36pt / iPad 40pt · radius 8/10 · текст Suisse Int'l Medium 13/14.

Select

Дропдаун со счётчиком: прячет варианты за одним контролом, раскрывает список в шторке. Для длинных списков.

iPhone 36pt / iPad 40pt · показывает имя значения или counter.

BottomSheetFilters

Шаблон шторки выбора (Шаблоны шторки / Фильтры) поверх Sheet Native. Вызывается из Select.

Header · поиск · список (List Item) · футер (Сбросить/Применить).

Типы выбора

В шаблон заложены 4 варианта логики. Отличаются изначальным состоянием, типом выбора и поведением кнопок.

ВариантСтартВыбор«Сбросить»Select после «Применить»× на Select
1. Сингл с дефолтом дефолт уже выбран (✓)одиночный есть; неактивна пока стоит дефолт имя значения сброс до дефолта
2. Мульти без дефолта всегда пустомножественный (по «ИЛИ») есть; неактивна пока пусто counter (число) очистка до пуста
3. Сингл без дефолта пустоодиночный есть; неактивна пока пусто имя значения + × очистка до пуста
4. Выбор города город всегда выбранодиночный, обязательный, с поиском нет — значение обязательно имя города — нельзя очистить

Множественный выбор всегда работает по принципу «ИЛИ» (значения объединяются). Единичный — при смене значения предыдущее сбрасывается.

Кнопки шторки: Применить / Сбросить

Применить

  • Присутствует всегда. Применяет выбор и закрывает шторку.
  • Выбор применяется только по этой кнопке.
  • В выборе города — на всю ширину (т.к. «Сбросить» нет).

Сбросить

  • Disabled, пока выбор не менялся (дефолт для №1, пусто для №2–3).
  • Активируется, как только выбор изменён.
  • Возвращает к изначальному состоянию (дефолт / пусто).
  • В выборе города кнопки нет.

Закрытие шторки без «Применить» (×, свайп вниз, тап по затемнению) — выбор не применяется: фильтр остаётся как был.

Показ поля поиска зависит от числа вариантов в списке.

Флоу и анимации

Поведение списка

  • Первое посещение — список в обычном порядке.
  • Повторное посещение — ранее выбранные пункты поднимаются наверх списка.
  • Снятие выбора при повторном входе — снятые айтемы остаются на местах; не выбранное ранее — в привычном порядке.

Перемещение выбранного в начало

  • Выбранный чип/селект переходит в начало строки фильтров.
  • Анимация перемещения — 300 ms после нажатия.
  • Подгрузка пунктов — скелетонами.

Отображение в Chips / Select

  • Выбран один пункт — показывается имя значения.
  • Выбрано 2 и более — показывается counter (число).

Состояния

Загрузка

После применения фильтра результаты подгружаются скелетонами (есть адаптивы под разные экраны).

Ничего не нашлось

Иллюстрация + «Увы, нам ничего не удалось найти» + «Попробуйте изменить фильтры или сбросьте их» + кнопка «Сбросить фильтры».

Недоступные теги

Пункты, под которые нет результатов, показываются disabled.

Сброс всех фильтров

При активных фильтрах в начале строки — круглая × (сброс всех). Активные чипы имеют индивидуальный ×.

Краевые случаи

  • Мульти всегда пуст на старте — у множественного выбора не бывает предвыбранных значений.
  • > 3 активных категорий — появляется кнопка сброса всех фильтров сразу.
  • Выбор города — обязателен: нет «Сбросить», нет × на чипе; выбранный город закреплён вверху, остальные по алфавиту; поиск всегда.
  • Закрытие без «Применить» — изменения не сохраняются.
  • Снятие выбора при повторном входе — порядок не «прыгает»: снятые остаются на местах.
  • Тип события — фильтр появляется только в сценарии входа через календарь.
  • Скролл страницы категории — строка фильтров залипает (sticky) над контентом.
  • Sort-шторка в каталоге — единичный с дефолтом, но кнопка одна: «Применить» на всю ширину, сброс вынесен на уровень страницы (отличается от шторки фильтра в Афише, где «Сбросить» — внутри). Два паттерна; требует унификации.

Применение в продукте

Афиша — строка фильтров

В гриде/каталоге сверху — горизонтальная строка: Chips для быстрых фильтров (В моей подписке, Высокий рейтинг, Новое) и Select для списочных (Сортировка, Жанр, Годы, Страна). Активный элемент уезжает в начало (300 ms).

Каталог-категория — экраны

Часть кейса про страницу коллекции — нерелевантна, на неё не ориентируемся.

Сценарии

A — мультивыбор «Жанр»

  1. Тап по Жанр → шторка «Жанры» (пусто, «Сбросить» неактивна; поиск если >20).
  2. Отмечаем Ужасы / Приключения / Комедии → «Сбросить» активна.
  3. «Применить» → селект показывает counter «Жанры · 3», уезжает в начало.
  4. Повторное открытие — выбранные сверху. × на селекте — очистка до пуста.

B — сортировка (сингл с дефолтом)

  1. Тап → «Рекомендуемые ✓» по умолчанию.
  2. Выбираем «А-Я» → предыдущее сбрасывается.
  3. «Применить» → чип показывает «А-Я».
  4. × на чипе — возврат к дефолту (не к пустому).

C — выбор города (уникальный)

  1. Чип города в шапке → полноэкранная шторка «Город».
  2. Поиск; выбранный город закреплён вверху, остальные по алфавиту.
  3. Нижних кнопок нет: применяется по «Применить» на всю ширину, сброса нет.
