Select

Компактный фильтр-дропдаун: по тапу раскрывает список опций, поддерживает множественный выбор и показывает счётчик выбранного. В отличие от Chips, прячет варианты за одним контролом — для длинных списков.

Draft 2026-05-22 · Платформа iOS (iPhone + iPad) · file rMcDm5qGp4CXkXXddEbcMh · node 34884:24858

  • Раскрывает список опций (dropdown / bottom sheet)
  • Множественный выбор со счётчиком выбранного (Counter)
  • 3 состояния: Rest, Touch, Disabled
  • 2 вида: закрытый (chevron ▾) и активный (counter + ×)
  • Адаптируется под iPhone (36pt) и iPad (40pt)
  • Входит в группу Filters вместе с компонентом Chips

Когда использовать обязательно

  • Длинный список опций (>10) — когда показывать все Chips на экране неудобно
  • Множественный выбор с подсчётом — «Жанры · 3», «Страны · 5»
  • Экономия места — один контрол вместо россыпи тегов

Анатомия обязательно

Пример — Selected=True: появляется counter (число выбранного) и крестик сброса вместо chevron.

① Контейнер
Горизонтальный auto-layout. Fill по State и Selected. Radius 8 (iPhone) / 10 (iPad).
② Leading icon
Опциональная иконка из набора Actions/* (свойство Icon). 16×16 / 20×20.
③ Text Box
Лейбл фильтра. Suisse Int'l Medium 13/14. Что выбираем — «Жанры», «Год».
④ Trailing — chevron ▾ или Counter + ×
Selected=False → chevron вниз (раскрыть). Selected=True → counter (число выбранного) + × (сбросить).

Состояния обязательно

Таблица состояний (State):

Rest · обычное

Touch · нажатое

Disabled · недоступно

⚠️ Состояний Loading / Progress нет — это специфика Button.

Selected компонент-специфично

Переключает trailing-часть и ширину контрола.

Selected = False · chevron ▾, ничего не выбрано

Selected = True · counter + ×, есть выбор

Counter компонент-специфично

Уникальная для Select часть — счётчик выбранного. Появляется при Selected=True и показывает, сколько опций выбрано из списка.

  • Назначение: мгновенно сообщить, что фильтр активен и сколько значений в нём
  • Значение: свойство String Counter (например «3»). Для больших чисел — «99+»
  • × рядом со счётчиком сбрасывает выбор одним тапом, не открывая список
  • При Counter=false активный Select показывает только × без числа

Иконка и текст рекомендовано

  • Иконка опциональна (Icon), только лидинг, из набора Actions/*
  • Текст — лейбл фильтра (что выбираем), не выбранное значение. Suisse Int'l Medium 13
  • Лейбл не меняется при выборе — количество показывает counter, а не текст

Как использовать обязательно

Select vs Chips

Do

Select для длинного списка (жанры, страны) — счётчик показывает выбор, список скрыт.

Don't

Select ради 2–3 вариантов — лучше показать их сразу как Chips, без лишнего тапа.

Лейбл

Do

Лейбл — категория: «Жанры», «Год», «Страна». Counter показывает количество.

Don't

Подставлять выбранные значения в лейбл («Драма, Триллер…») — для этого есть counter.

⚠️ Пары — драфт, требуют проверки дизайнером.
