Chips

Компактный элемент выбора одного из нескольких вариантов — обычно из списка тегов, категорий или фильтров. В отличие от Button, Chips живут группами и поддерживают состояние «выбран».

Draft 2026-05-20 · Платформа iOS (iPhone + iPad) · Источник: file jdBqhypltqMzx0mXE7uw94, node 34254:8865

  • 2 типа: с иконкой (Style=Icon) или с изображением/аватаром (Style=Img)
  • 3 состояния: Rest, Touch, Disabled
  • Поддержка toggle-логики через свойство Selected
  • Адаптируется под iPhone (36pt) и iPad (40pt)
  • Входит в группу Filters вместе с компонентом Select

Когда использовать обязательно

  • Фильтры контента — категории, жанры, годы, языки
  • Выбор из небольшого списка (3–10 вариантов), где dropdown был бы избыточен

Анатомия обязательно

Пример — Selected=True с trailing-крестиком. У выбранного чипа автоматически появляется Cross Box для быстрого снятия выбора.

① Контейнер
Горизонтальный auto-layout. Fill переключается по State и Selected. Selected=True — инвертированный (светлый фон, тёмный текст). Corner radius 8pt (iPhone) / 10pt (iPad).
② Leading icon
Иконка из набора Actions/* при Style=Icon. При Style=Img здесь круглое изображение во всю высоту, прижатое к левому краю без padding.
③ Text Box
Текст лейбла. Suisse Int'l Medium 13/14, letter-spacing 0.13. Truncate ending в одну строку — перенос запрещён.
④ Cross Box
Trailing × для снятия выбора. Появляется автоматически при Selected=True — поэтому ширина чипа 106pt (vs 88pt у Selected=False).

Стили / Тип рекомендовано

Style = Icon

Лидинг — иконка из набора Окко (Actions/Calendar_Bold, Filter_Bold, Geo_Bold...). Для функциональных фильтров: жанр, год, страна.

Style = Img

Лидинг — круглое изображение/аватар, прижат к левому краю. Для тематических фильтров: персоны, коллекции, бренды.

Selected компонент-специфично

Уникальная для Chips характеристика — выбран или нет. Связана с состоянием, но не равна ему.

Selected = False

Иконка рекомендовано

  • Используется только при Style=Icon
  • Источник: набор Actions / * (Calendar_Bold, Filter_Bold, Geo_Bold...)
  • Размер: 16×16 (iPhone), 20×20 (iPad)
  • Цвет: наследуется от текста состояния

Как использовать обязательно

Смешивание стилей в группе фильтров

Chips с иконкой, с картинкой и без лидинга, а также Select — могут спокойно сосуществовать в одной группе. Группируются по смыслу фильтра, а не по стилю.

Do
📅 2024  Том Хэнкс Драма Все жанры ▾

В одной группе: Chips Icon + Chips Img + Chips без лидинга + Select. Это нормальный кейс.

Длина текста

Do
Драма 2024 Россия

Короткий лейбл, 1–3 слова, описывающий категорию.

Don't
Фильмы про любо…

Длинная фраза обрезается — пользователь не видит, что выбрал.

Selected как состояние

Do
📅 2024 📅 2023 📅 2022

Selected реально сохраняет состояние и фильтрует контент ниже.

Don't
📌 Сейчас 📌 Ранее 📌 Скоро

Selected используется декоративно — для подсветки «текущего» без реакции системы.

Disabled vs скрытие

Do
HD4K8K

Disabled — когда вариант временно недоступен (4K требует подписки).

Don't
Лекции Подкасты Книги

Скрывать варианты через Disabled, когда логичнее их вовсе не показывать.
