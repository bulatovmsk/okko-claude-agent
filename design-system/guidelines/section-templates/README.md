# Section Templates

Шаблоны секций гайдлайна. Каждый файл = одна секция, описывает:

1. **Что включает** — обязательные и опциональные элементы
2. **Пример заполнения** — на реальном компоненте
3. **Источники для авто-заполнения** — откуда Skill берёт данные
4. **Что НЕ делать** — типовые ошибки

Полный каркас и порядок секций — см. [STRUCTURE.md](../STRUCTURE.md).
