# Секция 2 — Когда использовать

## Что включает

1. **Заголовок секции** — «Когда использовать»
2. **Список сценариев** — 2–4 буллета: типичные кейсы применения
3. **Иллюстрации в контексте** — 2–3 примера реальных экранов Окко с компонентом
   - Размер: `390×720` (iPhone) или `768×1024` (iPad)
   - Источник: либо реальный фрейм из библиотеки, либо скриншот из приложения

## Пример заполнения (Button)

```
Когда использовать

— Главный призыв к действию на экране (Смотреть, Купить, Подписаться)
— Подтверждение/отмена в диалогах и шторках
— Запуск процесса (вход, оплата, поиск)
— Быстрые действия в детальной карточке (трейлер, добавить в избранное)
```

С иллюстрациями (горизонтально):
- Экран детальной карточки (Phone) с Primary Button «Смотреть»
- Экран подписки (Phone) с Primary Button «Купить за 299 ₽»
- Экран iPad с Primary + Secondary buttons

## Источники для авто-заполнения

- **Сценарии** — Skill комбинирует:
  - Свойства компонента (например, есть Primary → есть кейс CTA)
  - Анализ библиотеки: где этот компонент инстанцирован → реальные кейсы использования
- **Иллюстрации** — Skill ищет в библиотеке фреймы с инстансами этого компонента и предлагает дизайнеру выбрать 2–3 типичных

## Что НЕ делать

- ❌ Не более 4 буллетов — иначе теряется фокус
- ❌ Иллюстрации должны быть **реальными экранами Окко**, не абстрактными примерами
- ❌ Если у компонента всего один сценарий — это сигнал, что секции не нужно, объединить с шапкой
