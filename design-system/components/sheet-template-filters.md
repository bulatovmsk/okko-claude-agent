# Шаблон шторки: Фильтры (Sheet template / Filters)

> Reference-карточка компонента. Источник: COMPONENT_SET `Шаблоны шторки / Фильтры` в Figma — file `rMcDm5qGp4CXkXXddEbcMh` (Lib-iOS), node `37390:49620`.
> Шаблон строится поверх [`🟢Sheet Native`](bottom-sheet-native.md) и **вызывается компонентом [`Select`](select.md)** при раскрытии списка опций.

## Назначение

Готовая шторка для выбора значений фильтра. Раскрывается из `Select` по тапу: показывает поиск, прокручиваемый список опций (с множественным/единичным выбором) и кнопки действий внизу. Один из «шаблонов шторки» — преднастроенных наполнений Sheet Native под типовые задачи.

## Анатомия

Инстанс `🟢Sheet Native` (Scrim + Sheet + Header), у которого `Slot Box` заполнен содержимым фильтра:

1. **Header** (48pt) — заголовок фильтра + кнопка закрытия (×).
2. **Search Input** (54pt, Searchbar) — поиск по списку опций.
3. **List** — прокручиваемый список строк `🟡 List Item V2` (52pt каждая) — выбираемые опции фильтра.
4. **Button Box** (футер) — две кнопки `Button` (190×48): **Сбросить** и **Применить**.

## Варианты фильтра и поведение кнопок

В шаблон заложены **4 варианта** логики выбора. Отличаются изначальным состоянием, типом выбора и поведением кнопок **Применить** / **Сбросить**, а также тем, что показывает `Select` после применения.

| Вариант | Изначальное состояние | Тип выбора | Кнопка «Сбросить» | `Select` после «Применить» | Действие × на `Select` |
|---|---|---|---|---|---|
| **1. Сингл с дефолтом** | дефолтное значение уже выбрано (✓) | одиночный | есть; **неактивна** пока стоит дефолт, активируется при отклонении | имя выбранного значения | сброс **до дефолта** |
| **2. Мульти без дефолта** | пусто, ничего не выбрано (всегда) | множественный | есть; неактивна пока пусто | counter (число выбранных) + × | очистка **до пуста** |
| **3. Сингл без дефолта** | пусто, ничего не выбрано | одиночный | есть; неактивна пока пусто | имя выбранного значения + × | очистка **до пуста** |
| **4. Выбор города** (уникальный) | город всегда выбран (напр. Москва) | одиночный, обязательный, с поиском | **нет** — значение обязательно | имя города | — (очистить нельзя) |

### Применение и отмена

- Выбор применяется **только по кнопке «Применить»**. Кнопка применяет текущий выбор и закрывает шторку.
- **Закрытие шторки без «Применить»** (крестик ×, свайп вниз, тап по затемнению) — выбор **не применяется**: фильтр остаётся в том состоянии, что был до открытия.
- В уникальном кейсе **выбора города** «Применить» — на всю ширину (т.к. «Сбросить» отсутствует).

### Кнопка «Сбросить»

- **Неактивна (disabled)**, пока выбор **не менялся** относительно изначального состояния: для варианта 1 — дефолтное значение, для вариантов 2 и 3 — пусто.
- **Становится активной**, как только пользователь **изменил выбор** относительно изначального.
- Возвращает выбор к изначальному состоянию (дефолт — для варианта 1; пусто — для 2 и 3).
- В варианте 4 (город) кнопки нет: город обязателен, сбросить «в пусто» нельзя.

### Поведение × на `Select` (после применённого фильтра)

- **Сингл с дефолтом** — × возвращает фильтр к дефолтному значению (не к пустому).
- **Мульти / Сингл без дефолта** — × очищает фильтр до пустого состояния.
- **Город** — крестика сброса нет.

### Уникальный кейс: выбор города

- Город обязателен и всегда имеет значение → нет «Сбросить», только «Применить» (на всю ширину).
- Есть **поиск** по городам («Найти город»).
- Выбранный город закреплён вверху списка, остальные — по алфавиту.
- Полноэкранная подача (поверх главного экрана), не компактная шторка.

> Источник логики: схема взаимодействия «Сингл с дефолтом / Мульти без дефолта / Сингл без дефолта / Выбор города» (прототип Окко).

## Когда использовать

- Раскрытие списка опций по тапу на `Select`
- Выбор значений фильтра с поиском и подтверждением (Применить / Сбросить)
- Длинные/прокручиваемые списки опций

## Когда НЕ использовать

| Сценарий | Вместо |
|---|---|
| Короткий список, помещается на экран | `Chips` (без шторки) |
| Произвольный контент шторки (не фильтр) | `BottomSheet` / `Sheet Native` напрямую |

## Связанные компоненты

- [`Select`](select.md) — вызывает этот шаблон при раскрытии
- [`Bottom Sheet Native`](bottom-sheet-native.md) — база, на которой собран шаблон
- `List Item V2` — строка опции в списке
- `Search Input` — поиск по списку
- `Button` — кнопки футера (Сбросить / Применить)

## Тех-долг

- ⚠️ Строки списка собраны на `🟡 List Item V2` — статус «в работе» (не финальный). Перепроверить при стабилизации компонента.
- ⚠️ Унаследован от Sheet Native: кнопка закрытия в хедере — `🔴 [Deprecated] mini Button`. См. [bottom-sheet-native.md](bottom-sheet-native.md).
