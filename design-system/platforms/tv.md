# TV — платформенные правила

Контекст: Android TV и SmartTV Web (LG webOS, Samsung Tizen). 10-foot UI: пользователь смотрит на экран с 2–4 метров, управление D-pad или ИК-пультом.

## Ключевое отличие от других платформ

- **Нет указателя, нет тача** — только D-pad и кнопки (OK, Back, Menu, Play/Pause).
- **Фокус — главное.** В любой момент один и только один элемент в фокусе, и пользователь должен видеть его без сомнений.
- **Расстояние просмотра** — всё крупнее: текст, hit-area, отступы.

## Focus management

### Визуально

- Focus-state **обязательно отличается** от не-focus: scale-up (обычно 1.05–1.1×), обводка, тень или их комбинация
- Focus-state **никогда не путать с hover** — TV не имеет hover
- Анимация перехода фокуса: 100–200ms ease-out

### Логически

- Соседние focusable элементы должны быть на одной линии (горизонтальной или вертикальной)
- D-pad движение между соседними элементами без пропусков
- Возврат фокуса при возврате на экран — на последний сфокусированный элемент
- Trap focus в модалках обязателен

## Hit-area (для focus, не для тача)

- Минимальный размер фокусируемого элемента: 80×80px при 1080p
- Между focusable элементами — пробел не менее 16px

## Состояния

- Default (не в фокусе)
- Focused (обязательно визуально выделено)
- Pressed (короткое — при нажатии OK)
- Disabled (visible но not focusable)
- Selected (для табов, чекбоксов и пр.)

## Что НЕ работает на TV

- Hover — нет указателя
- Touch gestures — нет таскрина
- Right-click контекстные меню — заменяются на Menu-кнопку пульта
- Hamburger menu — плохо для D-pad, использовать боковую панель
- Маленькие иконки без поясняющего текста — плохо различимы с 3 метров

## Перформанс на SmartTV Web

- Старые модели LG/Samsung — слабое железо, ограниченная GPU
- Избегать: больших размытий, тяжёлых градиентов, одновременных анимаций
- Использовать CSS transform/opacity (GPU-accelerated), не left/top/width
