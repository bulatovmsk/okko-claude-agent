# Error - Sheet

## Назначение

Модальное представление ошибки внутри нативной шторки. Сохраняет контекст
предыдущего экрана под scrim и помещает [Error - View](error-view.md) в слот
[Bottom Sheet Native](bottom-sheet-native.md).

## Когда использовать

- Когда ошибка относится к модальному или локальному сценарию и пользователь
  должен вернуться к предыдущему контексту после закрытия.
- Когда нужны иллюстрация, пояснение, одно или два восстановительных действия и
  блок обращения в поддержку, но отдельный экран ошибки избыточен.
- Для единой адаптивной сборки ошибки на Phone и iPad.

## Когда НЕ использовать

- Для ошибки, полностью заменяющей основной экран, — использовать
  [Error - View](error-view.md) напрямую.
- Для ошибки отдельного поля или небольшого блока — использовать локальное
  сообщение рядом с источником проблемы.
- Для краткого неблокирующего уведомления — использовать компактное уведомление.
- Не вкладывать Error Sheet в другую модальную шторку.

## Платформенные особенности iOS

| Device | Внешний вариант | Sheet | Error View в слоте |
|---|---:|---:|---:|
| `Phone` | 393×852 | 375×852 | 375×543.5 |
| `iPad` | 820×820 | 620×725 | 620×700 |

- На Phone панель занимает ширину 375 внутри внешнего frame 393 и прижата к низу.
- На iPad панель плавающая и центрирована; содержимое Error View растягивается
  до ширины слота.
- Error Sheet публикует только свойство `Device`. Настройки изображения, текстов,
  действий и support widget находятся во вложенном Error View и не подняты в
  свойства верхнего COMPONENT_SET.
- Для VoiceOver переводить фокус внутрь открывшейся модальной области, сначала
  сообщать заголовок ошибки, ограничивать навигацию содержимым шторки и после
  закрытия возвращать фокус к вызвавшему элементу.

## Связанные компоненты

- [Error - Fulscreen](error-fullscreen.md) — блокирующая ошибка в основном app shell.
- [Error - View](error-view.md) — содержимое ошибки в `Slot Box`.
- [Bottom Sheet Native](bottom-sheet-native.md) — контейнер, scrim и закрытие.
- `Sheet Native - Header` — нативный заголовок шторки.
- `BottomSheet / Scrim` — модальная подложка.
- `Mark / Star_Bold` — иконка внутри служебной кнопки заголовка.

## Тех-долг

- В живой цепочке зависимостей `🟢Sheet Native` → `Sheet Native - Header`
  используется `.🔴 [Deprecated] mini Button`. Это подтверждённый конфликт:
  готовый компонент шторки зависит от deprecated-кнопки. До замены учитывать его
  при аудите и не копировать этот паттерн в новые компоненты.
