# Rail - Highlights

## Назначение

Шаблон акцентного рейтингового рейла с крупной цифрой, тегом и обложкой. Внутренние `_Highlights / Digit` и `_Highlights / Tag` являются частями карточки.

## Когда использовать

- Для подборок, где позиция или выделенный статус карточки — главный смысл.
- Когда нужен крупный визуальный рейтинг внутри стандартной семьи Rail.

## Когда НЕ использовать

- Для обычной подборки без рейтинга используйте [Rail - Main](rail-main.md).
- Не озвучивайте декоративную цифру отдельно: объединяйте позицию и название карточки.

## Платформенные особенности iOS

- Размеры пяти `Device`-вариантов заметно различаются по высоте; используйте готовые мастера.
- На iPhone и iPad сохраняйте порядок рейтинга при горизонтальной прокрутке.
- Рейл прокручивается горизонтально, а каждая карточка остаётся отдельным интерактивным элементом с собственным доступным названием.
- Значения визуальных токенов сверяются с Tokens Studio source of truth и из Figma в карточку не переносятся.

## Связанные компоненты

- [Rail / Top Titles](rail-top-titles.md) — отдельный шаблон ТОП–10.
- [Rail / Mixed Top](rail-mixed-top.md) — рейтинг с пояснениями.
- [Rail - Base](rail-base.md).
