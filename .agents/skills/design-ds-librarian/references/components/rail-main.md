# Rail - Main

## Назначение

Основной готовый Rail-шаблон со стандартной горизонтальной контентной карточкой `_Main / Card` и обложкой `_Main / Cover`.

## Когда использовать

- Как базовый выбор для горизонтального ряда фильмов, сериалов или другого каталожного контента.
- Когда не требуется специальная форма карточки, прогресс, рейтинг или маркетинговая композиция.

## Когда НЕ использовать

- Для продолжения просмотра используйте [Rail - Continue](rail-continue.md).
- Для квадратных или вертикальных обложек выбирайте соответствующий Rail-шаблон.

## Платформенные особенности iOS

- `Device` содержит пять готовых вариантов iPhone/iPad.
- Карточки остаются отдельными фокусируемыми элементами в порядке контента.
- Рейл прокручивается горизонтально, а каждая карточка остаётся отдельным интерактивным элементом с собственным доступным названием.
- Значения визуальных токенов сверяются с Tokens Studio source of truth и из Figma в карточку не переносятся.

## Связанные компоненты

- [Rail - Medium](rail-medium.md) и [Rail - Large](rail-large.md) — другие уровни размера.
- [Rail - Base](rail-base.md) — общий каркас.
- [Семейство Rail](rail-family.md).
