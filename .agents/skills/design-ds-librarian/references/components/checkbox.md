# Checkbox

## Назначение

Элемент независимого бинарного выбора: пользователь отмечает или снимает
отметку, не покидая текущий контекст.

## Когда использовать

- Для выбора нескольких независимых пунктов из списка.
- Для согласия, подтверждения условия или включения дополнительной опции перед
  следующим действием.
- Когда результат выбора применяется вместе с отдельным подтверждающим действием.

## Когда НЕ использовать

- Для выбора ровно одного пункта из взаимоисключающей группы — использовать
  [Radio button](radio-button.md) или другой компонент одиночного выбора.
- Для настройки с немедленным системным эффектом — использовать
  [Switch](switch.md).
- Для кнопки-действия с сохраняемым выбранным состоянием — использовать
  [Button - Toggle](button-toggle.md).
- Не использовать `disabled` как способ скрыть обязательное условие: рядом
  должно быть понятно, почему выбор недоступен.

## Платформенные особенности iOS

- Визуальный размер компонента — **24×24** для всех вариантов.
- Интерактивная область должна быть не меньше 44×44 pt; при наличии подписи
  обычно включать в нажатие всю строку.
- `Checked=True` показывает отметку, `Checked=False` — пустой контейнер.
- `State=disabled` сохраняет checked-состояние, но блокирует изменение.
- Для VoiceOver объединять чекбокс с подписью, передавать текущее состояние
  выбора и недоступность; визуальная отметка не должна быть единственным сигналом.

## Связанные компоненты

- [Button - Toggle](button-toggle.md) — действие в виде кнопки с выбранным состоянием.
- `Notification / Check_Mark_Single_Bold` — иконка отметки внутри checked-варианта.
- [Radio button](radio-button.md) — одиночный выбор из взаимоисключающей группы.
- [Switch](switch.md) — настройка с немедленным эффектом.
