# Grid / Large

## Назначение

Адаптивная сетка крупных контентных карточек. Используется, когда элементы
каталога должны получить больше визуального веса, чем в основной сетке.

## Когда использовать

- Для подборок с крупными обложками и небольшим числом акцентных объектов.
- Когда `Grid / Main` визуально недостаточно выразителен, но featured-блок не
  нужен.
- Заголовок и его текст управляются `Heading` и `↳ Heading`.

## Когда НЕ использовать

- Для обычной плотности используйте [Grid / Main](grid-main.md), для одного
  главного объекта — Featured-компонент.
- Не используйте `_Large Grid Item` напрямую.

## Платформенные особенности iOS

- iPhone поддерживает только портретный вариант; для iPad есть обе ориентации.
- Точное значение `iPad  6/10` содержит два пробела.
- В VoiceOver каждая крупная карточка остаётся отдельным элементом; порядок
  чтения совпадает с визуальным порядком сетки.
- Визуальные токены проверяются в Tokens Studio source of truth.

## Связанные компоненты

- [Семейство Grid](grid-family.md) — сравнение с другими формами сетки.
- `_Large Grid Item` — внутренняя карточка, отдельно не публикуется.
- `Навигационные / Переход в коллекцию` — действие заголовка.
