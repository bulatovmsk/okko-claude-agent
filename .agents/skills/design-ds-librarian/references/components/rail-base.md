# Rail - Base

## Назначение

Базовый каркас семейства Rail. Управляет заголовком, его текстом, опциональным левым слотом и платформенной раскладкой; конкретные карточки задаются шаблонами `Rail - …`.

## Когда использовать

- Как основу при поддержке или создании публичного Rail-шаблона.
- Для настройки заголовка через `Heading`, `↳ Heading`, `Left Slot` и `↳ Left Slot`.

## Когда НЕ использовать

- Не используйте Base как готовый продуктовый рейл без конкретного типа карточки.
- Не регистрируйте внутренние `_Rail - Layout Ui Type` и `_Rail / Slot mini` как отдельные компоненты.

## Платформенные особенности iOS

- В Base два варианта `Device`: `iPhone` и `iPad`; конкретные шаблоны расширяют их до модельных раскладок.
- Булевы свойства управляют видимостью Heading и Left Slot, а вложенные свойства — их содержимым.
- Рейл прокручивается горизонтально, а каждая карточка остаётся отдельным интерактивным элементом с собственным доступным названием.
- Значения визуальных токенов сверяются с Tokens Studio source of truth и из Figma в карточку не переносятся.

## Связанные компоненты

- [Семейство Rail](rail-family.md) — все публичные шаблоны, построенные на Base.
- [Rail - Main](rail-main.md) — базовый продуктовый шаблон карточек.
