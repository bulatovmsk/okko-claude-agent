# Совместимость прежней команды

Выполни задачу iOS по соседнему навыку [build-ui-type](../build-ui-type/SKILL.md), прочитав общие правила и iOS reference. Остальные платформы включай, только если они запрошены.

Старая инструкция о пересчёте всех карточек по фактической ширине экрана отменена. Для iOS сохраняются утверждённые фиксированные размеры; Technical JSON используется для проверки. Main iPhone 15 остаётся 226 px: исходная база расчёта 390 px отличается от экранного макета 393 px.

Если build-ui-type не установлен рядом, найди его в репозитории okko-claude-agent в .agents/skills/build-ui-type. Не возвращайся к прежним копиям sizing.md как к актуальному правилу.
