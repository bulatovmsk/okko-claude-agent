## Hover/Focus

- **Hover** доступен только при наличии указателя (`@media (hover: hover)`)
- **Focus** обязателен на всех интерактивных элементах. Стиль focus отличается от hover.
- На mobile web hover-стили не применяются — используется только active.

## Hit-area

- Минимум 24×24 для clickable элементов на десктопе
- Минимум 44×44 на mobile web

## Иконки

- Размеры через токены `spacing.icon.*` или `size.icon.*`
- SVG only, цвет через `currentColor` или CSS-переменные ДС

## Цвета и legacy-исключение

- Новые макеты используют semantic-токены `color.*`.
- В существующей Web-реализации старые цветовые имена и значения могут сохраняться из-за ограничения платформы.
- Таблица перехода находится в [`tokens/colors.md`](../tokens/colors.md#c-переход-со-старых-цветов-на-semantic-токены).
- При аудите подтверждённый старый Web-цвет классифицируется как допустимое legacy-исключение и долг миграции. Не требуй его немедленной замены новым HEX.
- Исключение не разрешает вводить старые цвета в новые макеты, использовать произвольные HEX или автоматически переносить Web-ограничение на другие платформы.


## Доступность

- Tab-order осмысленный, focus-trap в модалках обязателен
- ARIA-разметка для нестандартных контролов
- Контраст AA минимум, AAA для основного текста где возможно

## Что НЕ типично для web

- Свайп-жесты — не делать опорой на десктопе, только дополнение для mobile web
- Long-press — не использовать на десктопе
