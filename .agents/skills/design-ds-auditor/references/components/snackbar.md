# Snackbar

## Назначение

Краткое неблокирующее уведомление поверх текущего экрана iOS. Показывает
сообщение в одну-две строки, опциональную сменную иконку и опциональное действие.
Без действия компонент может использоваться как toast-подобное пассивное
подтверждение; живое имя компонента в Figma — `Snackbar`.

## Когда использовать

- Для краткого подтверждения результата: операция завершена, настройка
  сохранена, элемент добавлен или удалён.
- Для обратимой операции с одним коротким последующим действием, если
  action-сценарий согласован с текущим ограничением компонента.
- `Text content` задаёт сообщение, `Icon` включает ведущую иконку, а `↳ Icon`
  заменяет её. В живом примере используется универсальная иконка успеха.
- `Action button=False` — пассивное уведомление; `Action button=True` —
  уведомление с одним действием.

## Когда НЕ использовать

- Для ошибки, требующей решения или блокирующей сценарий, используйте
  [Error - Sheet](error-sheet.md) либо
  [Error - Fulscreen](error-fullscreen.md).
- Для длинного объяснения, формы или нескольких действий используйте экран или
  [Bottom Sheet Native](bottom-sheet-native.md).
- Не используйте Snackbar как постоянный статус или элемент навигации.
- Не добавляйте новое action-применение без проверки дизайн-системы: внутри
  `Action button` сейчас находится `🔴 [Deprecated] Button`, а текст действия
  не опубликован как верхнеуровневое свойство Snackbar.

## Платформенные особенности iOS

- Опубликованы два device-варианта: iPhone — 300×64 pt, iPad — 348×76 pt.
- Визуальный пример подтверждает сообщение в одну-две строки. Для более длинного
  текста выбирайте устойчивый контейнер, а не увеличивайте Snackbar произвольно.
- Размещайте уведомление поверх контента с учётом safe area, Tabbar, клавиатуры
  и других нижних оверлеев; оно не должно перекрывать критичное действие.
- VoiceOver должен объявлять новое сообщение без неожиданного перевода фокуса.
  Срочность объявления выбирайте по смыслу, а не по наличию иконки.
- Не скрывайте Snackbar до того, как пользователь успеет прочитать или услышать
  сообщение. При наличии действия оставляйте достаточно времени и давайте
  доступную кнопку с конкретным названием.
- Иконка не должна быть единственным носителем смысла; декоративную иконку не
  озвучивайте отдельно, если содержание уже передано текстом.

## Связанные компоненты

- [Button](button.md) — актуальный компонент действия; Snackbar пока использует
  устаревшую внутреннюю кнопку.
- [Bottom Sheet Native](bottom-sheet-native.md) — для длинного или
  интерактивного сообщения.
- [Error - Sheet](error-sheet.md),
  [Error - Fulscreen](error-fullscreen.md) — ошибки, требующие внимания.
- `Snackbar / Универсальный успех`,
  `Notification / Check_Mark_Single_Bold` — иконка успеха по умолчанию.
- `Mark / Star` — зависимость устаревшей action-кнопки.
