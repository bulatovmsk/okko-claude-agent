# Rail / Mixed Top

## Назначение

Рейл «самое популярное сегодня» с разными основаниями рейтинга. Каждая позиция
сочетает обложку, пояснение вроде количества оценок, рецензий, добавлений в
избранное или отзывов, а также компактные метаданные контента.

## Когда использовать

- Для блока ежедневной популярности, когда рядом с каждым тайтлом нужно
  объяснить, по какому сигналу он попал в подборку.
- В ленте главной страницы: на планшетах элементы располагаются горизонтально,
  на мобильных — в более высокой композиции с заголовком над карточками.
- Выбирайте готовое значение `Resolution`: `1366`, `1024`, `768`, `iPhone 8`
  или `iPhone SE`.
- Сохраняйте пояснение рейтинга вместе с соответствующей карточкой и не
  смешивайте разные основания популярности в одном элементе.

## Когда НЕ использовать

- Для простого нумерованного топа без пояснений используйте
  [Rail / Top Titles](rail-top-titles.md).
- Для набора тематических подборок используйте
  [Rail / Top Collections](rail-top-collections.md).
- Не используйте внутренние `_Mixed Top / …` напрямую: это адаптивные запчасти
  мастера, а не публичные компоненты.

## Платформенные особенности iOS

- Пять вариантов покрывают ширины 320, 375, 768, 1024 и 1366 pt; высота
  мобильной композиции заметно больше планшетной: 343–397 pt против 220–297 pt.
- Названия мобильных вариантов `iPhone 8` и `iPhone SE` отражают текущие имена
  Figma и не должны автоматически трактоваться как ограничение только этими
  моделями устройств.
- Use case подтверждает горизонтальное пролистывание карточек на мобильных
  экранах и размещение рейла внутри основной ленты.
- Для VoiceOver объединяйте название тайтла, причину попадания в топ и ключевые
  метаданные в один доступный элемент; декоративные ветви рейтинга исключайте
  из озвучивания.
- Figma сообщает `CHANGED`: у мастера есть изменения относительно опубликованной
  версии библиотеки.

## Связанные компоненты

- [Label : Small](label-small.md) — подтверждённая зависимость, node
  `12185:97090`.
- [Label : Large](label-large.md) — связанное семейство меток. В живом мастере
  Mixed Top зависимость указывает на node `39976:32660`, тогда как сохранённая
  карточка Label : Large использует node `12185:97166`; это конфликт источников,
  который нельзя разрешать автоматически.
- [Rail / Top Titles](rail-top-titles.md) и
  [Rail / Top Collections](rail-top-collections.md) — альтернативные виды топов.
