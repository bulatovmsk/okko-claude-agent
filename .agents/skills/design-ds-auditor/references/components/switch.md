# Switch

## Назначение

Переключатель бинарной настройки между включённым и выключенным состоянием.
Изменение применяется непосредственно при переключении.

## Когда использовать

- Для независимой настройки со значениями «включено» и «выключено».
- Когда изменение можно применить сразу, без отдельной кнопки подтверждения.
- В строке настройки с постоянной понятной подписью.

## Когда НЕ использовать

- Для выбора нескольких пунктов перед подтверждением — использовать
  [Checkbox](checkbox.md).
- Для выбора одного значения из группы альтернатив — использовать
  [Radio button](radio-button.md).
- Для действия-кнопки с выбранным состоянием — использовать
  [Button - Toggle](button-toggle.md).
- Не использовать без подписи, если смысл состояний нельзя однозначно понять
  из контекста.

## Платформенные особенности iOS

- Размер опубликованного компонента — **52×28**.
- Интерактивная область должна быть не меньше 44×44 pt; в строке настроек
  обычно включать в нажатие всю строку.
- `Checked=True` означает включённое состояние, `Checked=False` — выключенное.
- `State=disabled` сохраняет значение, но блокирует переключение.
- Для VoiceOver использовать семантику переключателя, понятную подпись и
  передавать состояния «включено/выключено» и недоступность.
- Если применение требует времени, не менять смысл Switch на кнопку запуска:
  состояние интерфейса должно однозначно отражать фактическое значение настройки.

## Связанные компоненты
