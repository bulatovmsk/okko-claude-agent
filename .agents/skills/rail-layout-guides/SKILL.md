# Layout guides Rail

Используй [параметры и применение](references/guides.md) и, для продолжения существующей работы, [снимок стилей](references/style-state.json) от 13 ноября 2026. Проверь текущие стили в UI Type, прежде чем создавать новые.

При работе через Plugin API прочитай применимые инструкции figma-use. Сетки — нативные GridStyle, а не component set и не новая коллекция переменных.

## Правила

- Применяй стиль к фрейму полной ширины экрана. Колонки STRETCH растягиваются, но стиль автоматически не переключается по ширине.
- Стили Web: Mobile (320, 375), Tablet (768, 1024), Desktop M (1440), Desktop L (1920). Пары с одинаковыми параметрами используют общий стиль. Desktop разделён из-за padding и gap.
- Над Web-примерами нужны явные подписи breakpoint=320, 375, 768, 1024, 1440, 1920; полное имя свойства у каждой подписи, например breakpoint=375. Значения включены также в названия стилей и заголовки групп.
- Web 440 — только «Пример растяжения», дополнительный breakpoint не вводится.
- Android: Phone и Tablet. Tablet общий для 640 и 1024; специальной правой полосы R нет.
- Web-колонки являются вспомогательными: их число не заменяет расчёт ширины Rail Card через N. Android gutter сетки 8/12 не заменяет gap карусели 6/8.
- Импортируй существующие screen-padding и spacing-переменные; используй локальные rail/gap-horizontal/*. Новые переменные/aliases/коллекции не создавай.
- Существующие iOS/iPhone и iOS/iPad сохраняй, если пользователь не попросил менять их.

## Проверка

Проверь назначенный gridStyleId, STRETCH, количество колонок, offset, gutter, правую полосу и фактические variable bindings. На собственной временной копии измени ширину и убедись, что колонки растягиваются. Подписи breakpoint и ширина фрейма должны совпадать.

Обычный экспорт изображения не показывает нативные layout guides. Проверка подписей по экспорту не доказывает видимость сетки: читай свойства стиля и при необходимости проверяй UI с включёнными guides.
