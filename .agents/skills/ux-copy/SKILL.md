# Okko UX Copy

Проверяй интерфейсные тексты на точность, простоту, пользу, уважительный тон и согласованность с продакшном.

## Источники

1. Сначала прочитай [контекст продукта](references/okko-context.md).
2. Для норм языка и терминов используй [Редполитику](references/editorial-policy.md).
3. Если нужна проверка согласованности с текущим продуктом, прочитай [правила поиска по продакшн-референсу](references/production-ref.md) и найди примеры в `references/production-reference/`.
4. Не считай продакшн-строку автоматически правильной: это прецедент, а Редполитика имеет приоритет при подтверждённом конфликте.

## Вход

- Если пользователь прислал текст, работай с ним напрямую.
- Если пользователь прислал Figma-ссылку, извлеки только релевантный текст доступными Figma-инструментами. Перед вызовами соблюдай обязательные prerequisite skills текущей среды.
- Если прочитать Figma нельзя, кратко попроси прислать текст; не останавливай текстовые задачи из-за отсутствия Figma.
- Для корректной редактуры учитывай назначение элемента, действие пользователя, состояние интерфейса и ограничения длины. Если контекст критичен и его нельзя вывести, задай один короткий вопрос.

## Режим проверки

Для каждого подтверждённого нарушения укажи исходный фрагмент, правило и причину. Не называй вкусовое предпочтение нарушением.

Верни:

1. `Нарушения` — нумерованный список или «Нарушений нет».
2. `Вариант А — минимальные правки` — исправь только подтверждённые проблемы.
3. `Вариант Б — переработка` — предложи более прямую формулировку, если она полезна.
4. `Похожее из прода` — 1–3 релевантных примера с путём токена; пропусти раздел, если совпадений нет.

## Режим консультации

На общий вопрос ответь кратко, сославшись на конкретный раздел Редполитики. Добавь 1–2 продакшн-примера только когда они действительно подтверждают ответ.

## Ограничения

- Не выдумывай правила, токены и продакшн-примеры.
- Сохраняй смысл, юридически значимые условия и продуктовые ограничения.
- Не расширяй задачу до полного редизайна сценария без запроса.
- Синхронизацию с Confluence выполняй только по явному запросу и только при наличии подходящего подключённого инструмента; протокол описан в [confluence-sync.md](references/confluence-sync.md).
