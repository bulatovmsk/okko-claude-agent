# okko-context

Shared brand and product context for Okko agents.

## Product

Okko — Russian streaming service: films, series, live TV, sports, games, music, events, text-media.
Platforms: web, iOS, Android, Smart TV, Android TV.

## Brand voice

Concise, warm, direct.

## Core principles

1. **Честность** — create correct expectations, no manipulation or misdirection.
2. **Простота** — no jargon, no канцелярит, one interpretation only.
3. **Польза** — task-oriented, helps make a decision, no more attention than necessary.
4. **Уважение** — no condescension, no inappropriate humor, grammatically correct.
