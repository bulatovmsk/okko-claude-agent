**Исторический референс.** По решению пользователя от 2026-09-22 отдельное решение Context Menu для Web заменено модификацией существующего Dropdown только на десктопных брейкпоинтах. Для текущей работы читай [Dropdown · Desktop Web](dropdown-web.md): его свойства, запчасти и токены имеют приоритет над данными ниже. Это решение не отменяет отдельный Context Menu Android и не задаёт поведение iOS.

## Содержание и иллюстрации

- Меню поддерживает Content = Select List / Custom Slot и BG Style = Blur / Solid. Select List собирается из `_Context Menu / Building Items`, Custom Slot принимает пользовательское наполнение; айтемы документируются отдельно. В паспорте оставляем публичные свойства Context Menu, в том числе управляющие вложенными частями, но не API самих айтемов, Profile и других запчастей. Предлагаемый API явно подписываем.
- Для размеров показываем четыре примера: ширина по содержимому, ширина вручную, высота по содержимому, ограниченная высота с внутренней прокруткой.
- Иллюстрируем сборку слота, фактические состояния айтемов, пары Do/Don't, последовательность открытия и закрытия. Сохраняем схему позиционирования и обновлённые пользовательские скрины применения.
- **Trim:** верхнее затемнение обозначает скрытое продолжение списка выше, нижнее — ниже. На соответствующей границе затемнение исчезает; если список помещается целиком, оба скрыты. Это отдельные элементы от полосы прокрутки. В анатомии показываем оба Trim на инстансе и явно подписываем промежуточную позицию прокрутки.
- **На Web анимации нет.** Не добавляем анимацию в схемы и технические рекомендации.
- **Fallback:** при недоступном или неработающем blur, а также в предусмотренном режиме для слабых устройств используем непрозрачную поверхность из макета. Принятый вариант — `color/fill/solid/secondary`, `#1B1A1D`, 100%, без blur. Обычная поверхность — `color/fill/glassy/secondary`, `#3B3A3E`, 48%, эффект `Blur(Web Only)/Primary`, радиус 16. При обновлении сверяем значения и привязки в Figma; не придумываем автоматическое определение слабого устройства или новый API.
- Собственные отступы контейнера: Desktop — 6 сверху/снизу (`spacing/125`) и 8 слева/справа (`spacing/150`); Tablet — 4 сверху/снизу (`spacing/100`) и 6 слева/справа; Mobile — 4 со всех сторон. Скругление: Desktop/Tablet — `corner-radius/700` (16), Mobile — `corner-radius/500` (12). Сверяй привязки при последующих изменениях.
- Ссылки оформляем фиолетовым; в принятом гайде используется `#AD85FF`. При наличии соответствующего стиля или переменной библиотеки переиспользуем их.

Объём этих решений — документация Web. Изменение исходных компонентов, реализации и добавление новых свойств не входят в обновление гайда.
