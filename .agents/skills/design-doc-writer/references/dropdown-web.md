## Решение и источники

Не переносить сюда Mobile Web, Android/iOS, Ripple или мобильную анимацию. Публикация модификации и состояние реализации не проверены; не присваивать lifecycle `ready` или `design-only` по одному макету.

**Custom Slot сохранён:** пользователь добавил его во время обновления документации. На момент проверки он представлен вариантом Content и вложенными фреймами `Slot`, а не отдельным свойством Figma типа `SLOT`. Не обещать поддержку нативного SLOT без повторной проверки. В гайде сборка показана подписанной схемой: связанный инстанс контейнера и отдельное пользовательское наполнение. Не менять исходный компонент и не отсоединять инстансы ради иллюстрации.

Select List собирается из `_Dropdown - Select Item`. У запчасти есть Rest, Hover, Disabled, Loading, Skeleton; Selected — отдельная отметка выбора. Текст, дополнительный текст и иконка принадлежат запчасти. В паспорте контейнера не перечислять её подробный API. Custom Slot может содержать профили, разделители и действия; такие примеры подписывать как пользовательское наполнение, а не обязательную анатомию списка.

## Сохранённые правила

- Открытие по клику; появление, исчезновение и смена поверхности без анимации. Hover относится к пунктам, уход курсора не закрывает Dropdown.
- Ширина — по самому широкому содержимому всего списка с отступами либо вручную; ограничивается доступной шириной окна. Прокрутка не меняет ширину. Горизонтальную прокрутку не использовать.
- Высота — по содержимому либо заданная, ограничивается maxHeight и доступным пространством; переполнение прокручивается внутри.
- Dropdown привязан к источнику вызова: предпочтительно снизу; при нехватке места — сверху, сдвиг внутрь окна и ограничение высоты на стороне с большим пространством. Пересчитывать при изменении окна; не обрезать родительским контейнером.
- Выбор доступного действия/одного значения, нажатие снаружи, повторный клик по источнику и смена контекста закрывают меню. Внутренняя прокрутка, неинтерактивные заголовки/разделители и недоступный пункт не закрывают. После отмены возвращать фокус источнику, если пользователь не перевёл его на другой элемент.
- Закрытие при прокрутке окружающей страницы, перемещающей источник, остаётся предложением. Клавиатурный контракт требует согласования; не выдавать его за подтверждённую реализацию.
- Верхний Trim обозначает скрытое продолжение выше, нижний — ниже; на соответствующей границе исчезает. Когда список помещается, оба скрыты. Полоса прокрутки — отдельная часть. В коде индикаторы определяются содержимым и положением прокрутки; значения Figma — настройки демонстрации.
- При недоступном/неработающем blur или предусмотренном ограничении производительности использовать Solid: одновременно отключить blur и заменить полупрозрачную заливку на непрозрачную. Геометрия и поведение сохраняются. Критерии слабого устройства и обнаружения сбоя не определены.

## Документация и API

Сохранять отдельные гайд и паспорт, взаимные фиолетовые ссылки (#AD85FF), пользовательские скрины и их порядок. Текстовую анатомию дополнять связанным инстансом и выносками: контейнер, содержимое, пункт, отметка выбора, Scroll, верхний и нижний Trim. Для Trim показывать переполнение и подписывать промежуточную позицию прокрутки.

Сохранять четыре иллюстрации размеров, сборку Custom Slot, состояния запчасти, Do/Don't, открытие/закрытие, позиционирование и сравнение Blur/Solid. Проверять концы выносок после замены инстансов, обрезку, ссылки и связи с актуальными компонентами.

API в паспорте — **предлагаемое уточнение контракта существующего Dropdown**, не подтверждённый новый API. В нём сохранены trigger/anchor, children/content, open, width, height, maxHeight, placement, offset, viewportPadding, closeOnSelect, disabled, surfaceMode и события onOpenChange/onSelect. Имена сопоставить с кодовой библиотекой; не добавлять новые свойства по догадке. Открытые вопросы: токены offset/viewportPadding, клавиатурный контракт, критерии фоллбэка, имена API. Паспорт содержит только собственные свойства, токены и стили контейнера; запчасти — ссылками.
