# Секция 1 — Шапка

## Что включает

1. **Большой заголовок** — имя компонента (англ. или рус., как принято в библиотеке).
2. **Подзаголовок** — 1–2 строки: что это и для чего.
3. **Список ключевых характеристик** — 3–5 буллетов.
4. **Якоря-чипы** — пилюли-ссылки на разделы документа.

## Пример заполнения (Button)

```
Button

Базовый элемент управления — позволяет пользователю инициировать действие.
Универсален: подходит для CTA, навигации, переключателей.

— Поддерживает 3 типа (Primary / Secondary / Ghost) и 2 размера
— Состояния: Rest / Touch / Disabled / Loading / Progress
— Может содержать иконку, текст или их комбинацию
— Соответствует HIG по hit-area (44pt)

[Возможности] [Принципы] [Где использовать] [Анатомия] [Настройки]
```

## Источники для авто-заполнения

- **Имя компонента** — из имени компонента в библиотеке
- **Подзаголовок** — Skill спрашивает у дизайнера или генерирует из описания компонента
- **Характеристики** — выводятся из properties компонента (variants, sizes, states)
- **Якоря** — генерируются по списку секций, которые будут в гайдлайне

## Что НЕ делать

- ❌ Не вставлять подзаголовок длиннее 2 строк — это шапка, не введение
- ❌ Не дублировать в характеристиках то, что подробно раскроется в секциях ниже
- ❌ Якорные чипы не должны вести на отсутствующие секции — генерируются ПОСЛЕ принятия решения о составе секций
