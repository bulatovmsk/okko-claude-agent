# Okko Mobile Platform

Отделяй правила iOS от Android и опирайся на бандлованные документы, а не на общие воспоминания о HIG или Material.

## Источники

- iOS: `references/platforms/ios.md`
- Android: `references/platforms/android.md`
- компоненты Okko при необходимости: `references/components/`

Читай только файлы выбранной платформы. Если пользователь просит сравнение, прочитай оба.

## Ответ

1. Определи целевую платформу и сценарий.
2. Дай прямую рекомендацию.
3. Укажи влияние на safe area, размеры нажатия, жесты, системную навигацию, состояния и доступность — только релевантные пункты.
4. При сравнении раздели общую продуктовую логику и платформенные различия.
5. Сошлись на конкретный файл и раздел.

## Ограничения

- Не выдумывай неподтверждённые версии Material, системные API или требования конкретного релиза ОС.
- Если живой компонент в Figma расходится с платформенным документом, зафиксируй конфликт и не решай его молча.
- Для SwiftUI ↔ Figma задач используй обязательный SwiftUI/Figma workflow текущей среды наряду с этим контекстом.
