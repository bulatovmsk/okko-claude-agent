# Rail / Top Collections

## Назначение

Рейл тематических топ-подборок. Каждый элемент объединяет короткое название
топа и визуальный стек обложек, а несколько элементов располагаются в
горизонтальной ленте. Внутренний `_Top Collections / element` используется как
запчасть и не регистрируется самостоятельным компонентом.

## Когда использовать

- Когда нужно показать несколько редакционных или жанровых топов рядом:
  например, «в жанре ужасы», «у молодёжи», «русские сериалы».
- В ленте главной страницы как горизонтальный блок тематических подборок.
- Выбирайте `Resolution` по ширине целевого макета. Для мобильных экранов в
  живом мастере предусмотрены `320_simple`, `375_simple` и `414_simple`.
- Сохраняйте композицию логотипа TOP, заголовка и стека обложек; меняйте
  содержимое через предусмотренные вложенные элементы.

## Когда НЕ использовать

- Для единого рейтинга позиций от 1 до 10 используйте
  [Rail / Top Titles](rail-top-titles.md).
- Для карточек с пояснением причины популярности и метаданными используйте
  [Rail / Mixed Top](rail-mixed-top.md).
- Не используйте внутренний `_Top Collections / element` напрямую и не
  пересобирайте стек обложек вручную.

## Платформенные особенности iOS

- Опубликовано восемь значений `Resolution`; размеры варьируются от `320×236`
  до `1366×361`.
- В текущем мастере варианты `Resolution=320` и `Resolution=375` скрыты на
  холсте, а варианты с суффиксом `_simple` видимы. До отдельного подтверждения
  для мобильных макетов используйте видимые `_simple`-варианты.
- Use case подтверждает применение на ширинах 414, 768 и 1024 pt внутри
  вертикальной ленты главной страницы.
- Каждый топ должен быть отдельным доступным элементом. VoiceOver-лейбл должен
  передавать название подборки; декоративные фоновые обложки не должны
  дублироваться как несколько самостоятельных изображений.
- Figma сообщает `CHANGED`: у мастера есть изменения относительно опубликованной
  версии библиотеки.

## Связанные компоненты

- [Rail / Top Titles](rail-top-titles.md) — единый нумерованный топ-10.
- [Rail / Mixed Top](rail-mixed-top.md) — рейтинг отдельных тайтлов с
  пояснениями.
- `logo-TOP-COLLECTIONS`, `element/false/320`, `element/true/320`,
  `element/true/375` — опубликованные вложенные зависимости мастера.
