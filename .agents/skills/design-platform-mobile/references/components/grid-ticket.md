# Grid / Ticket

## Назначение

Адаптивная сетка билетов и специальных предложений. Объединяет заголовок и
карусель ticket-карточек в готовые раскладки для iPhone и iPad.

## Когда использовать

- Для билетов, мероприятий и промо-предложений, представленных карточками
  ticket-формата.
- Когда нужен готовый ряд с device-вариантом, а не ручная раскладка `_itemGrid`.
- `Heading` выключайте только при наличии внешнего заголовка раздела.

## Когда НЕ использовать

- Для каталожного контента используйте [Grid / Main](grid-main.md) или
  [Grid / Content](grid-content.md).
- `_itemGrid` и `_Cover` — внутренние запчасти, их нельзя выбирать как
  самостоятельные компоненты.

## Платформенные особенности iOS

- Свойство называется `device` со строчной буквы. Доступны шесть точных
  значений от `iPhone SE` до `iPad Pro`.
- Размер и число видимых карточек задаются вариантом устройства; не
  растягивайте мастер вручную.
- В VoiceOver билет озвучивается одним элементом с названием, датой и
  ключевым статусом; логотип Live и обложку отдельно не дублируйте.
- Визуальные токены проверяются в Tokens Studio source of truth.

## Связанные компоненты

- [Семейство Grid](grid-family.md) — карта публичных шаблонов.
- [Label : Small](label-small.md) — одна из вложенных меток.
- `Logotypes / Live` и `Навигационные / Переход в коллекцию` — публичные
  зависимости без отдельных рабочих карточек.
