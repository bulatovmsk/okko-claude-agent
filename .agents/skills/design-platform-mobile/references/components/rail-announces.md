# Rail - Announces

## Назначение

Шаблон горизонтального рейла для анонсов. Использует собственную внутреннюю карточку `_Announces / Card` и обложку `_Announces / Cover` внутри общего каркаса Rail.

## Когда использовать

- Для ряда анонсов, где изображение и короткая подпись образуют самостоятельную карточку.
- Когда нужен готовый адаптивный шаблон анонсов для iPhone и iPad.

## Когда НЕ использовать

- Для стандартного каталога используйте [Rail - Main](rail-main.md) или подходящий размерный шаблон.
- Не публикуйте и не используйте `_Announces / Card` отдельно от шаблона.

## Платформенные особенности iOS

- Свойство `Device` содержит пять готовых раскладок iPhone/iPad.
- Высота вариантов не растёт монотонно с шириной устройства: используйте мастер, а не пересчитывайте геометрию вручную.
- Рейл прокручивается горизонтально, а каждая карточка остаётся отдельным интерактивным элементом с собственным доступным названием.
- Значения визуальных токенов сверяются с Tokens Studio source of truth и из Figma в карточку не переносятся.

## Связанные компоненты

- [Rail - Base](rail-base.md) — общий каркас и заголовок.
- [Семейство Rail](rail-family.md) — выбор между шаблонами.
