# Radio button

## Назначение

Элемент одиночного выбора: пользователь выбирает один вариант из группы
взаимоисключающих значений.

## Когда использовать

- Когда все основные варианты выбора нужно показать одновременно.
- Для короткой группы, в которой разрешено выбрать только один пункт.
- Когда выбранное значение остаётся видимым до подтверждения или продолжения
  сценария.

## Когда НЕ использовать

- Для нескольких независимых вариантов — использовать [Checkbox](checkbox.md).
- Для бинарной настройки с немедленным эффектом — использовать
  [Switch](switch.md).
- Для действия с сохраняемым выбранным состоянием — использовать
  [Button - Toggle](button-toggle.md).
- Не показывать одиночный Radio Button без группы альтернатив: бинарный выбор
  лучше выразить Checkbox или [Switch](switch.md) в зависимости от сценария.

## Платформенные особенности iOS

- Визуальный размер компонента — **24×24** для всех вариантов.
- Интерактивная область должна быть не меньше 44×44 pt; при наличии подписи
  обычно включать в нажатие всю строку.
- `Checked=True` обозначает выбранный вариант, `Checked=False` — невыбранный.
- `State=disabled` сохраняет checked-состояние, но блокирует изменение.
- В одной группе в каждый момент может быть выбран только один доступный пункт.
- Для VoiceOver объединять Radio Button с подписью, передавать выбранность,
  недоступность и положение в группе; визуальный круг не должен быть
  единственным сигналом.

## Связанные компоненты

- [Checkbox](checkbox.md) — независимый множественный выбор.
- [Button - Toggle](button-toggle.md) — действие-кнопка с выбранным состоянием.
- [Switch](switch.md) — бинарная настройка с немедленным эффектом.
- Живая нода не содержит внешних component dependencies.
