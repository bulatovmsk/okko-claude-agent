# Android Grid в UI Type

Состояние на 19 ноября 2026. После слияния ветки «Правки» в мастер UI Type вошли восемь Android-наборов, всего 27 вариантов. У каждого набора своя страница с именем `<тип> Grid`. Имена основных наборов имеют форму `Grid <тип> 🤖 Android`.

## Варианты и зазоры

В ячейках указаны ширина компонента, число колонок и межкарточные зазоры в формате «горизонталь × вертикаль». Размеры в px. Ширину компонента измеряем на мастере, поэтому она может быть меньше ширины экрана. Прочерк означает одну колонку.

## Поведение при изменении ширины

- Grid передаёт ширину рядам, ряд делит полезную ширину поровну между колонками, карточка и её обложка заполняют полученную ширину. Высота рядов рассчитывается по содержимому. Число колонок задаёт вариант устройства.
- Связанные Rail Card и специализированные карточки сохраняют пропорции обложек. Main, Large и Content используют 16:9, Vertical и Ticket — 2:3, Square и Circle — 1:1. Подпись под обложкой занимает собственную высоту. В Person фото сохраняет размер для устройства, а текст переносится внутри колонки. В неполном ряду Person пустые ячейки сохраняют ширину колонки.
- Лейблы на обложках по умолчанию выключены. Подписи и метаданные Person остаются видимыми по настройкам карточки.
- Проверку проводим на экземпляре при сужении и расширении. Сверяем фактические зазоры, равенство ширин, пропорции обложек и перенос текста. Используем существующие дизайн-переменные.

В текущем Content использованы стандартная обложка Rail и двухпольная подпись. Оформление рейтинга и длительности из исходника ещё предстоит перенести. Данные описывают мастера Figma, статус публикации библиотеки отдельно не проверялся.
