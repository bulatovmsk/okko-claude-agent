# Rail / Top Titles

## Назначение

Контентный рейл рейтинга «ТОП–10 недели». Показывает заголовок рейтинга и
горизонтальную последовательность из десяти пронумерованных обложек. Внутренние
компоненты `_TOP 10 /Топ` и `_TOP 10 / Цифра` являются запчастями и отдельно в
библиотеке знаний не регистрируются.

## Когда использовать

- Для недельного топа фильмов или другого контента, когда порядок позиций от 1
  до 10 является главным смыслом блока.
- Как самостоятельный горизонтальный рейл внутри ленты главной страницы.
- Выбирайте готовое значение `Resolution`, соответствующее целевому устройству:
  `iPad Pro`, `iPad 1024`, `iPad 768`, `iPhone` или `iPhone SE`.
- Заголовок, цифры рейтинга и геометрию карточек сохраняйте как единую
  композицию компонента; контент обложек меняется через вложенные ячейки.

## Когда НЕ использовать

- Для тематических подборок без числового рейтинга используйте
  [Rail / Top Collections](rail-top-collections.md).
- Для рейтинга с пояснением причины популярности и метаданными у каждой позиции
  используйте [Rail / Mixed Top](rail-mixed-top.md).
- Не собирайте номера рейтинга и обложки вручную из внутренних `_…`-компонентов.

## Платформенные особенности iOS

- В Figma опубликованы пять разрешений: от `320×191` для `iPhone SE` до
  `1366×336` для `iPad Pro`.
- На мобильных и планшетных примерах рейл выходит за видимую ширину экрана и
  рассчитан на горизонтальный просмотр контента.
- В use case для экрана шириной 414 pt экземпляр имеет ширину 414 pt, хотя
  отдельного значения `Resolution=414` нет: используется растянутый вариант
  `iPhone`. Это расхождение нужно перепроверять при актуализации.
- Рейл сам не является одной кнопкой: интерактивными должны оставаться карточки
  внутри него. Для VoiceOver сохраняйте порядок «позиция рейтинга → название» и
  не озвучивайте декоративную цифру отдельно от карточки.
- Figma сообщает `CHANGED`: у мастера есть изменения относительно опубликованной
  версии библиотеки.

## Связанные компоненты

- [Rail / Top Collections](rail-top-collections.md) — рейл тематических топов
  без сквозной нумерации 1–10.
- [Rail / Mixed Top](rail-mixed-top.md) — рейтинг с пояснением и метаданными.
- `x / Кавер`, `Ячейка / 1024`, `Ячейка / 320 New`, `Ячейка / 375 New` —
  опубликованные зависимости для обложек разных разрешений.
