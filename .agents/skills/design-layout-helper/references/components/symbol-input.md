# Symbol input

## Назначение

Поле для ввода короткого кода фиксированной длины на iOS. Значение разбито на
пять визуальных ячеек, поэтому пользователь видит заполненные позиции, текущую
позицию ввода и оставшееся количество символов.

## Когда использовать

- Для пятисимвольного проверочного кода, PIN или другого короткого значения,
  которое вводится последовательно по одному символу.
- `State=default` — пустое поле; `typing` — частично введённое значение и
  активная позиция; `complete` — заполнены все пять ячеек; `disabled` — ввод
  недоступен; `error` — значение отклонено.
- В `State=error` задавайте понятное объяснение через свойство `Error text`.
- Используйте соответствующий `Device` для iPhone или iPad: компонент меняет
  размер ячеек, но сохраняет пять позиций.

## Когда НЕ использовать

- Для текста переменной или неизвестной длины используйте
  [Text input](input.md).
- Не используйте компонент для кода другой длины без отдельного подтверждённого
  варианта: живая структура содержит ровно пять `_Symbol input / Item`.
- Не делайте каждую ячейку отдельным полем ввода и отдельной остановкой
  VoiceOver: визуально это пять позиций, семантически — одно значение.
- Не показывайте ошибку только красной границей; заполняйте `Error text`.

## Платформенные особенности iOS

- iPhone: пять ячеек 40×48 pt с интервалом 12 pt; общая ширина 248 pt.
  Базовые состояния имеют высоту 48 pt, `error` с подписью — 80 pt.
- iPad: пять ячеек 44×52 pt с интервалом 12 pt; общая ширина 268 pt.
  Базовые состояния имеют высоту 52 pt, `error` — 86 pt.
- В `typing` активная ячейка показывает курсор и нижний индикатор; в
  `complete` заполнены все позиции; в `disabled` контраст снижен; в `error`
  индикаторы и подпись показывают ошибку.
- Обрабатывайте всю группу как одну область ввода. На iPhone ширина отдельной
  ячейки меньше 44 pt, поэтому ячейки не должны становиться самостоятельными
  touch targets.
- Для проверочного кода включайте системное автозаполнение one-time code, если
  это соответствует продуктовому сценарию. Тип клавиатуры выбирайте по
  допустимому набору символов, а не по внешнему виду примера.
- VoiceOver должен объявлять назначение поля, длину кода, прогресс заполнения и
  `Error text`; вставка кода целиком должна заполнять позиции последовательно.

## Связанные компоненты

- [Text input](input.md) — поле для значения переменной длины.
- `_Symbol input / Item` — внутренняя ячейка; пять экземпляров образуют поле.
