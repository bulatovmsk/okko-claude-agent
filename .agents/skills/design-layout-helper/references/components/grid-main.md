# Grid / Main

## Назначение

Основная адаптивная сетка каталожного контента. Содержит заголовок и готовую
раскладку стандартных карточек с обложками для поддерживаемых устройств и
ориентаций.

## Когда использовать

- Как базовый выбор для экранной сетки фильмов, сериалов и другого каталога.
- Выбирайте `Device` и `Landscape` по целевой раскладке, сохраняя готовое число
  колонок и размеры карточек.
- `Heading` и `↳ Heading` используйте для управления наличием и текстом
  заголовка.

## Когда НЕ использовать

- Для вертикальных, квадратных, крупных или контентно-насыщенных карточек
  используйте соответствующий шаблон из [семейства Grid](grid-family.md).
- Не собирайте экран из `_Grid Main / Card` и `_Grid Main / Cover`.

## Платформенные особенности iOS

- iPhone представлен только портретным вариантом `Landscape=False`; для iPad
  6/10 и iPad Pro 13 есть обе ориентации.
- Точное значение `iPad 6/10` в этом мастере содержит один пробел.
- В VoiceOver сохраняйте визуальный порядок карточек и отдельное доступное
  название каждой карточки.
- Визуальные токены проверяются в Tokens Studio source of truth.

## Связанные компоненты

- [Семейство Grid](grid-family.md) — альтернативные формы карточек.
- `_Grid Main / Card` и `_Grid Main / Cover` — внутренние детали мастера.
- `Навигационные / Переход в коллекцию` — действие заголовка.
