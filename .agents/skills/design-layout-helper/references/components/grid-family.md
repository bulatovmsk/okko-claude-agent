# Grid — семейство шаблонов

## Модель семейства

Страница `UI Type Grid` содержит несколько самостоятельных публичных
`COMPONENT_SET`. Каждый `Grid / …` — готовый адаптивный шаблон секции с
заголовком и раскладкой карточек определённой формы. Это не один мастер с
единой осью типа карточки, поэтому публичные сетки зарегистрированы отдельно.

Ноды с именами `_…`, DevKit-части и секция `Deprecated` не являются
самостоятельными решениями. Они используются внутри мастеров, но отдельно в
память компонентов не записываются.

## Как выбирать шаблон

| Шаблон | Назначение | Варианты |
|---|---|---|
| [Grid / Main](grid-main.md) | основная каталожная сетка | 5 device/orientation |
| [Grid / Content](grid-content.md) | карточки с прогрессом, метками и действием загрузки | 5 device/orientation |
| [Grid / Vertical](grid-vertical.md) | вертикальные постеры | 5 device/orientation |
| [Grid / Square](grid-square.md) | квадратные карточки, компактно или раскрыто | 10 device/orientation/expanded |
| [Grid / Large](grid-large.md) | крупные акцентные карточки | 5 device/orientation |
| [Grid / Circle Zvuk](grid-circle-zvuk.md) | круглые карточки аудиоконтента Звука | 5 device/orientation |
| [Grid / Person](grid-person.md) | персоны и участники | 4 breakpoint, только Dark |
| [Grid / Ticket](grid-ticket.md) | билеты и специальные предложения | 6 device |

## Общие правила

- Используйте публичный мастер `Grid / …`, а не собирайте секцию из DevKit или
  `_…`-частей.
- Сохраняйте точные имена свойств Figma. В частности, `Grid / Main` содержит
  `iPad 6/10`, а пять других мастеров — `iPad  6/10` с двумя пробелами.
- iPhone у сеток `Main`, `Content`, `Vertical`, `Square`, `Large` и
  `Circle Zvuk` не имеет `Landscape=True`; не выдумывайте отсутствующую
  комбинацию.
- `Heading` управляет видимостью заголовка, а `↳ Heading` — его текстом там,
  где это свойство опубликовано.
- Карточки внутри сетки остаются отдельными интерактивными элементами.
  Порядок VoiceOver должен совпадать с визуальным порядком.
- Все восемь мастеров на момент проверки имеют Figma publish status `CHANGED`:
  в файле есть неопубликованные изменения, которые нужно учитывать при
  следующей актуализации.
- Цвета, отступы, размеры типографики и другие значения токенов проверяются в
  Tokens Studio source of truth, а не переносятся из Figma.
