# Rail - Marketing

## Назначение

Шаблон рейла с крупными маркетинговыми креативами `_Marketing / Card` и `_Marketing / Cover`.

## Когда использовать

- Для промо-кампаний и редакционных акцентов, где изображение несёт самостоятельное маркетинговое сообщение.
- Когда креатив должен занимать больше вертикального пространства, чем обычная карточка каталога.

## Когда НЕ использовать

- Для нейтрального каталога используйте [Rail - Main](rail-main.md).
- Не размещайте важный интерфейсный текст только внутри растрового креатива без доступного названия карточки.

## Платформенные особенности iOS

- Пять `Device`-вариантов имеют собственную композицию и размеры.
- Проверяйте читаемость локализованного креатива и доступное имя каждой карточки.
- Рейл прокручивается горизонтально, а каждая карточка остаётся отдельным интерактивным элементом с собственным доступным названием.
- Значения визуальных токенов сверяются с Tokens Studio source of truth и из Figma в карточку не переносятся.

## Связанные компоненты

- [Rail - Background](rail-background.md) — брендированная зона с фоном.
- [Rail - Large](rail-large.md) — крупная, но не маркетинговая карточка.
- [Rail - Base](rail-base.md).
