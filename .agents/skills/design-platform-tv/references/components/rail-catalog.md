# Rail - Catalog

## Назначение

Экспериментальный шаблон каталожного рейла с внутренними `_Main / Card` и `_Main / Cover`. В Figma помечен `🟡` и «Нет в проде».

## Когда использовать

- Только для изучения или продолжения уже согласованного эксперимента Catalog.
- После отдельного подтверждения готовности компонента к продуктовой работе.

## Когда НЕ использовать

- Не выбирайте автоматически для новых продуктовых макетов: компонент ещё не в проде.
- Для готового базового каталога используйте [Rail - Main](rail-main.md).

## Платформенные особенности iOS

- Свойство `Device` содержит пять раскладок от iPhone 15 до iPad Pro 13.
- Статус публикации `CHANGED`; перед первым продуктовым использованием требуется актуализация.
- Рейл прокручивается горизонтально, а каждая карточка остаётся отдельным интерактивным элементом с собственным доступным названием.
- Значения визуальных токенов сверяются с Tokens Studio source of truth и из Figma в карточку не переносятся.

## Связанные компоненты

- [Rail - Main](rail-main.md) — ближайший готовый шаблон.
- [Rail - Base](rail-base.md) — общий каркас.
- [Семейство Rail](rail-family.md) — карта всех шаблонов.
