# Bottom Sheet Native (Sheet Native)

> Reference-карточка компонента. Источник: COMPONENT_SET `🟢Sheet Native` в Figma — file `rMcDm5qGp4CXkXXddEbcMh` (Lib-iOS), node `37371:7396`.
> Префикс `🟢` = компонент готов/опубликован. Отличать от кастомного `BottomSheet` (гайд `28934:239837`): Native опирается на системное представление шита (native sheet presentation) платформы.

## Назначение

Нативная нижняя «шторка» (bottom sheet) — модальная панель, выезжающая снизу поверх контента с затемнением фона. Использует системный механизм представления; контент задаётся через слот. Применяется для второстепенных действий, списков выбора, форм поверх текущего экрана.

## Анатомия

1. **Scrim** — затемняющая подложка под шитом (чёрный, прозрачность **56%**). Управляется свойством `Scrim`.
2. **Sheet** — контейнер панели. Скруглён радиусом **16**:
   - iPhone — только верхние углы (`16/16/0/0`), панель прижата к низу экрана;
   - iPad — все углы (`16`), панель плавающая/по центру.
3. **Header** (высота 48) — шапка типа `Primary`: слот `Title` + кнопка закрытия (mini button, ×).
4. **Slot Box** — слот для контента (swap-наполнение под задачу).

## Когда использовать

- Второстепенные действия и формы поверх текущего экрана без перехода
- Списки выбора (раскрытие опций `Select`)
- Контент, для которого нужен системный жест закрытия (свайп вниз) и затемнение фона

## Когда НЕ использовать

| Сценарий | Вместо |
|---|---|
| Кастомные шторки с нестандартными detent/высотой/жестами | `BottomSheet` (кастомный, гайд `28934:239837`) |
| Полноэкранный сценарий / отдельный шаг флоу | отдельный экран (push) |
| Короткое уведомление | [Snackbar](snackbar.md) |

## Связанные компоненты

- [Error - Sheet](error-sheet.md) — готовая сборка ошибки в слоте нативной шторки.
- `BottomSheet` (кастомный) — когда нужен контроль над detent, максимальной высотой, областью свайпа
- `Select` — раскрывает свой список опций именно в шите
- Header — переиспользуемая шапка `_🛠️Sheet Native - Header` (тип Primary)
