## Общие решения

Пользователь попросил применять общие правила кнопок других платформ. Это относится к назначению и сценариям, но не разрешает переносить отсутствующие Web-стили, размеры или состояния. Назначение сопоставлено с локальными карточками iOS; старый iOS-гайд Button `31214:29705` при проверке не найден.

Три Breakpoint: Mobile 320+, Tablet 600+, Desktop 1720+. В обоих Web-наборах Mobile не имеет Hover и Focus; Tablet/Desktop имеют. Состояние нажатия называется Pressed, не Touch.

## Button

917 уникальных вариантов, дублей при проверке нет.

- Style: Primary, Secondary, Ghost, Negative, Sber.
- Shape: Rectangle, Circle ↓, Circle →. Text: true / false.
- Size: Large, Default, Small, ExtraSmall. ExtraSmall — только Rectangle / Secondary; высота 28 / 32 / 32 px.
- State: Rest, Hover, Focus, Pressed, Disabled, Loading, Progress. Progress есть только у части Rectangle-комбинаций; нельзя достраивать декартову матрицу.
- Circle → — Default/Small и Primary/Secondary/Negative; Circle ↓ Large — только без текста. Sber — Rectangle.
- Публичные поля: ↳ Text (TEXT), Icon (BOOLEAN), ↳ Icon Instance (INSTANCE_SWAP), Tooltip (BOOLEAN). Tooltip обнаружен в Hover.
- Общие сценарии: Primary — главное действие, Secondary — дополнительное, Ghost — минимальный акцент, Negative — опасное действие, Sber — сценарий Сбера. Соответствие Negative и iOS Danger использовано как правило назначения, не как тождество реализации. SberPay в Web-наборе отсутствует.

## Button Toggle

832 уникальных варианта, дублей при проверке нет.

- Style: Primary / Secondary. Не переносить Ghost из iOS или Negative/Sber из Button.
- Size: Small / Default / Large; ExtraSmall нет.
- Shape: Rectangle, Circle ↓, Circle →; Text: true / false.
- Large: Rectangle с текстом и без, Circle ↓ только без текста. Circle →: Default/Small, только с текстом.
- Selected: False / True — самостоятельная VARIANT-ось со строковыми значениями. State: Rest, Hover, Focus, Pressed, Disabled, Loading; Progress нет.
- Публичные поля: ↳ Text (TEXT), Icon (BOOLEAN), ↳ Icon Instance и ↳ Selected Icon Instance (INSTANCE_SWAP). Tooltip нет.
- Selected=False использует ↳ Icon Instance, Selected=True — ↳ Selected Icon Instance. Icon управляет видимостью графического слота в обоих состояниях.
- Назначение — обратимое действие с сохраняемым выбором, например избранное. Pressed не означает Selected=True. Для разового действия нужен Button, для системной настройки — Switch, для фильтра — Chips/Select.
- В этой задаче созданы только гайд и паспорт Toggle. Новую полную матрицу Overview для Toggle не собирали.

## Оформление и границы подтверждённости

Гайд и паспорт разделены и связаны фиолетовыми ссылками. Компоновка — по [общему эталону](../../design-doc-writer/references/component-presentation.md): компонент слева, гайд в центре, паспорт справа, общая секция с пустым именем. В гайдах есть анатомия с номерными выносками, настройки, формы, размеры, состояния, иконки/отступы/текст, Do/Don't, схема экрана; у Toggle дополнительно выбор и поведение. Все демонстрации — связанные инстансы.

Паспорта перечисляют собственные токены, стили и зависимости; размеры icon slot относятся к публичной геометрии, внутренние токены вложенных запчастей не раскрываются. Количество собранных привязок — 95 у Button после дополнения иконок, 79 у Toggle; не использовать эти числа как источник актуальных токенов.

API кода, события, клавиатурное взаимодействие, момент изменения Selected при сетевом запросе, повторное нажатие в Loading, доступность и анимации не проверены. Продакшн-скриншоты не предоставлены: контекстные экраны обозначены как схемы, таблицы свойств — не снимки панели Figma.

Background Solid Primary и Secondary взяты из библиотечных привязок. Background Solid Third не удалось найти в доступных Figma-источниках; внутренние поверхности оставлены с локальной заливкой. Это известное отклонение комплекта, не утверждение об отсутствии токена в source of truth и не новый стандарт. При дальнейшей работе сверить актуальный токен и привязать его, если доступен.
