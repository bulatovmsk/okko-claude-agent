## Геометрия и состояния

|---|---|---|---|

| Левый отступ | 14 / 16 / 18 | 18 / 20 / 22 | 20 / 28 / 36 |
| Gap | 6 / 8 / 8 | 8 / 10 / 10 | 10 / 12 / 12 |
| Radius | 8 / 10 / 12 | 10 / 12 / 14 | 12 / 14 / 16 |

Геометрия корня использует существующие `control/{small|default|large}/…/{phone|tablet|desktop}`. Подпись — соответствующий стиль Button Small / Button Default / Button Large. Large: Desktop 23/28, Tablet 20/26, Mobile 17/22 (font size/line height).

**Левая иконка:** по новому указанию пользователя от 12 октября ширина и высота во всех 84 вариантах привязаны к `control/{size}/text-icon/icon-size/{device}`. Это заменяет прежнее решение о фиксированных размерах слева. Значения Mobile / Tablet / Desktop: Small 14 / 18 / 22 px, Default 18 / 20 / 26 px, Large 22 / 26 / 28 px.

**Правая иконка:** сохраняется отдельное решение пользователя — Mobile 18 px, Tablet 22 px числом. Desktop пользователь настраивает сам: обычно 24 px, в отдельных вариантах иные размеры и привязка `control/default/text-icon/icon-size/desktop`. Не нормализуй её молча.

Правая иконка находится в `Trailing Icon`: горизонтальный auto layout, Hug по ширине, Fill по высоте, центрирование по вертикали. Правый padding корня — 0. Правый padding контейнера связан с `control/small/filter-icon/padding-horizontal/{device}` для всех трёх размеров. Не заменяй этот токен обычным отступом text-icon. Desktop-значение менялось пользователем; проверяй живую привязку и свежий источник.

- Selected=False: стрелка вниз. Selected=True: `Actions / Cross_Small_Bold`.
- Для `glassy/third` Hover и Focus используют опубликованный Paint Style `color/fill/glassy/hover-focus/third` того же уровня, с привязанными gradient Step_1/Step_2. Не оставляй Rest-заливку и не подменяй её другим уровнем.
- Selected использует `color/fill/solid/inverse`; отдельного hover-токена для inverse при проверке не было. Не выдумывай его.
- Focus — отдельная белая обводка 1 px, opacity 56%, отступ 2 px, radius корня + 2. В Select слой называется `_Select - Border`; это не связанный экземпляр `_Button - Border`. Проверяй растяжение при смене текста/видимости счётчика. Focus — Desktop/Tablet.

## Каталог, документация и ограничения

Пользователь подтвердил: **Select используется в каталоге в общей группе с Chips**. Гайд должен показывать их вместе над выдачей. Chips раскрывают короткие/быстрые варианты прямо в строке; Select открывает список. Filters Catalog отвечает за компоновку группы; Dropdown — связанный десктопный список, не вложенная часть Select.

Selected=False: вся площадь открывает список. Selected=True: основная часть открывает список, правая зона сбрасывает выбор. Не смешивай open, Selected и Pressed. Переключение Selected только при открытии, прототипные события и API кода не подтверждены. У текущего Dropdown значения breakpoint — 1720/1320; соответствие 600+/320+ и мобильный способ раскрытия требуют решения.

Гайд и паспорт разделены, имеют взаимные ссылки. В гайде — анатомия с выносками, настройки, размеры, состояния, иконки/текст, отступы, Do/Don't, зоны нажатия, Dropdown и схема каталога Chips + Select. В паспорте — реальные свойства Figma, привязки, стили, зависимости и явно **предлагаемый**, не подтверждённый API.

Схема каталога не является production-скриншотом, таблица настроек — не снимок панели Figma. Клавиатура, лимит/обрезание подписи, применение множественного выбора и кодовая интеграция не проверены; не присваивай Ready. В iOS-гайде противоречивая формулировка переключения Selected при открытии, а секция состояний содержит Chips. Не копируй эти ошибки в Web.

## Оформление комплекта

Гайд и паспорт обновлены 12 октября: три размера, 84 варианта, токены левой иконки, примеры Large и актуальные выноски. Используй [общее оформление](../../design-doc-writer/references/component-presentation.md): Background Solid Primary → Secondary → Third по уровням видимых поверхностей. Последнюю правку фоновых привязок пользователь внёс в макет сам.

В Overview ячейки должны вмещать инстанс и полную подпись: Hug по высоте с минимальной высотой для ровной сетки. Для текущего Large минимум 220 px, Default/Small — 180 px. После изменения геометрии проверяй обрезку подписей родительскими строками. Не дублируй подзаголовок в шапке.
