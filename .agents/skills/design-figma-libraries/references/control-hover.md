# Hover контролов: соответствие основной заливке

Правило подтверждено пользователем 23 октября 2026. Применяй при выборе стиля, редактировании и документировании web-контролов.

## Выбор эффекта

Hover выбирается по типу основной заливки:

| Основная заливка | Hover-эффект |
|---|---|
| Primary | Соответствующий Primary Hover |
| Glassy | Соответствующий Glassy Hover |
| Solid | Соответствующий Solid Hover |

Это соответствие семантических семейств. Точное имя Primary-стиля ищи в существующей библиотеке; не конструируй имя токена по этой таблице.

## Значения по умолчанию для контролов

| Выбор | Основная заливка | Стиль эффекта |
|---|---|---|
| Невыбранный контрол | `color/fill/glassy/third` | `color/fill/glassy/hover-focus/third` |
| Selected | `color/fill/solid/inverse` | `color/fill/solid/hover-focus/inverse` |

«Неактивный» в этом правиле означает невыбранный контрол, а не Disabled. Disabled не получает hover-эффект.

## Сборка слоёв

Основная заливка сохраняется. Hover-эффект появляется отдельным слоем поверх неё, под текстом, изображением и иконками. Скругление и размер слоя повторяют контейнер. Обводка состояния остаётся отдельным слоем.

Слой `Hover Effect` сразу блокируй (`locked = true`), чтобы он не перехватывал выбор при клике в редакторе. При исправлении hover блокируй также существующие слои эффекта в разрешённой области. Это блокировка выбора слоя в Figma, а не отключение действия кнопки или прототипа.

После правки мастера проверь связанные экземпляры в Overview и гайде в рамках задачи: переопределённая базовая заливка может остаться поверх нового состояния и исказить результат, особенно в светлой теме. Сравни заливку и слой эффекта с мастером, проверь вид в затронутых темах. Исправляй только подтверждённые ошибочные overrides адресно, сохраняя намеренные примеры и прочие настройки.

При добавлении эффекта используй пустой FRAME `Hover Effect`: абсолютное позиционирование, x/y = 0, размер контейнера, Stretch по обеим осям, без обводки и отступов. Сохраняй радиусы и существующие привязки радиусов контейнера; при клонировании образца проверяй, что его привязки подходят целевому размеру.
