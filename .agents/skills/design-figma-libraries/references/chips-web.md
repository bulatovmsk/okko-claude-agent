## Согласованная структура

- `Size`: **Default / Small**; оба обязательны в этой задаче.
- `Breakpoint`: Mobile 320+ / Tablet 600+ / Desktop 1720+.
- `Style`: Icon / Img; `Selected`: False / True.
- Mobile: Rest, Pressed, Disabled. Tablet и Desktop: Rest, Hover, Focus, Pressed, Disabled.
- 52 варианта на размер, всего **104**. Два Overview содержат по 52 связанных инстанса. Пустые Mobile Hover/Focus — допустимые отсутствующие сочетания.
- `Text` — подпись во всех вариантах.
- `Show Icon` — Boolean для ведущей иконки и компенсации **только Style=Icon**.
- `Icon` — Instance swap ведущей иконки **только Style=Icon**.
- Для Img пользователь явно не хочет Boolean. Не добавляй Show Image; отдельного публичного Image property не было.
- Selected и Pressed — разные оси: устойчивый выбор и момент взаимодействия.

После клонирования Default определения свойств остались, но привязки слоёв потерялись. Исправлены Text, visibility и instance swap; проверены временные инстансы всех 104 вариантов с изменением текста и Show Icon false/true. При дальнейших клонах проверяй реальные componentPropertyReferences и результат переключения, а не только наличие поля в панели.

## Переменные и стили

Пользователь запретил привязки геометрии к библиотеке iOS и дублирующую коллекцию цветов. Геометрия привязана к существующей локальной **Component W&M**. Цвета остаются ссылками на общую цветовую библиотеку: external/remote само по себе не означает iOS. Не создавай локальную Color и не копируй весь набор токенов ради компонента.

Семейства геометрии: `control/{small|default}/height`, `radius`, `text-icon/padding-horizontal`, `text-icon/gap-horizontal` с суффиксами phone/tablet/desktop. Правый отступ крестика: small/filter-icon/padding-horizontal или default/icon-only/padding-horizontal. Точные привязки сверяй в слоях.

Вложенная рамка состояний — `_Button - Border`. Не превращай параметры вложенных запчастей в публичный API Chips.

- iOS-гайд содержит неточности: секция «Стили» смешивает размер и Icon/Img; пример Img мог показывать иконку. В гайде фильтров порог поиска ровно 20 не определён. Не переносить эти утверждения без проверки.
