## Подтверждённая конструкция

- Белая карточка с указателем из двух кружков. Высота зависит от текста.
- Картинка справа, привязана к правому нижнему краю карточки и выступает вверх. Она не определяет высоту белого контейнера. Как в TV, величина выступа зависит от высоты текста; не заменяй эту конструкцию картинкой целиком внутри карточки.
- `Image overflow slot` резервирует место справа в Auto Layout, имеет Fill по высоте и отключённый clipping. Внутри — обычный прямоугольник `Image` с image fill и абсолютным позиционированием, constraints MAX/MAX. У Surface, Content и корня clipping выключен.
- Картинка не является отдельной запчастью: нет вложенного INSTANCE, отдельного main component и свойства Image asset. Изображение заменяется через заливку слоя.
- `Show image` управляет видимостью резервирующего контейнера и освобождает место для текста.
- Крестика и Close-компонента нет. По решению пользователя закрытие происходит по действию на экране; конкретное действие определяется экранным сценарием. Не возвращай закрытие по Escape как согласованное требование.
- Пользователь добавил стиль тени `S:9456da77b4c04f6c8fbd048273617c119b81ef28,`; он сохранён на корне всех вариантов. Перед правкой перечитай актуальный effectStyleId.

## Варианты и свойства

12 вариантов: `Device` × `Beak`.

- Device: `Mobile 0+`, `Tablet 600+`, `Desktop 1720+` (именно 0+, не 320+).
- Beak: `Left`, `Right`, `Top`, `Bottom`; название обозначает сторону указателя.
- TEXT: `Primary text#46898:15`, `Secondary text#46898:16`.
- BOOLEAN: `Show secondary text#46898:17`, `Show image#46898:18`; по умолчанию true.
- Отдельной оси состояний, центрирования текста и instance swap нет.

Это геометрия текущего дизайна, не канонические значения токенов. Текст использует соответствующие платформенные стили Web Tooltip; актуальные токены проверяй через DS Librarian. Desktop сохраняет конструкцию, которую пользователь одобрил перед добавлением брейкпоинтов.

## Исправленный дефект свойств

При клонировании Desktop в Tablet/Mobile определения свойств набора сохранились, но `componentPropertyReferences` новых слоёв оказались пустыми. Исправлены 24 привязки в восьми новых вариантах:

- Primary text: characters → Primary text.
- Secondary text: characters → Secondary text, visible → Show secondary text.
- Image overflow slot: visible → Show image.

Проверка: во всех 12 вариантах изменены оба текста и выключены/включены оба BOOLEAN с чтением фактических `characters` и `visible` слоёв экземпляра. Дополнительно проверено сохранение пользовательского текста и скрытия при переключении всех 12 комбинаций Device/Beak. Все проверки прошли; временные экземпляры удалены. Чтение только `instance.componentProperties` не проверяет работоспособность привязок.
