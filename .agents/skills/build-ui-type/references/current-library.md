## Состояние и ограничения

Карточки трёх платформ перенесены в UI Type, токены gap/radius перепривязаны. Общая шапка создана с Desktop. Выполнены пересборки, очистка дублей, переиспользование запчастей и унификация нейминга. Следующий рабочий этап — последовательная проверка типов с дизайнером.

Старые отчёты называли несовместимые по пропорции типы отложенными. После добавления Custom и разрешения полностью кастомных карточек это причина откладывания отменена. Нельзя из этого автоматически заключать, что все отложенные Person, Personal Widget, Subscriptions, Announces и Tracks уже собраны: проверяй фактическое наличие и состояние.

Открытые вопросы: точный токен внутренних Rail Card Padding Gap; хранение Web R/N в Technical; правила адаптации между опорными Web-брейкпойнтами. Публикация новой библиотеки не подтверждена. Не отмечай эти пункты завершёнными по одному наличию мастеров.
